# PRD: 自研云-主机申领-私有镜像支持

## 用户故事

作为 **指定业务的用户**，我希望在**主机申领 / 购买主机**的实例配置中的**镜像选择器**能看到**私有镜像选项**，以便选择团队统一使用的自定义 OS 版本镜像。

## 背景与动机

### 为什么需要私有镜像
- 业务希望 OS 版本统一，便于维护
- 云上提供的通用镜像，即使同一个镜像 ID，不同时间段对应的内核版本可能不同
- 业务需要使用经过内部适配的自定义 OS 版本

### 当前限制
- HCM 镜像选择器仅返回公共镜像列表，不支持按业务维度展示私有镜像

## 功能范围

> **变更边界明确**：仅修改镜像选择器的数据源逻辑（增加私有镜像数据），不改动镜像选择器的 UI 组件结构、布局或样式。不影响其他表单项和流程。

### 核心功能：镜像选择器列表扩展

#### 功能点 1：镜像列表数据源增加私有镜像（多场景适配）

| 项目 | 说明 |
|------|------|
| 改动范围 | 仅限镜像选择器组件的数据获取/渲染逻辑 |
| 触发位置 | 实例配置 → 镜像选择区域 |
| 控制依据 | 业务 ID（支持多种来源，见下方场景说明） |
| 目标业务 | 由后端接口根据业务 ID 自动判断并返回 |

#### 功能点 1.1：使用场景与业务 ID 来源

镜像选择器 (`cvm-image-selector.vue`) 在以下页面中被复用，各场景的业务 ID 来源不同：

| 场景 | 页面/组件 | bizId 来源 | 说明 |
|------|----------|-----------|------|
| 主机库存匹配面板 | `match-panel/common-resource/index.tsx` | `useWhereAmI().getBizsId()` 全局 hook | 资源管理模块下，路由有 bizs query |
| 主机申领表单 | `application-form/index.tsx` | `order.value.model.bkBizId` (BusinessSelector) 或 `getBizsId()` | 服务请求下的主机申领页，用户手动选业务 |
| CVM生产单据 | `cvm-produce/create-order/index.vue` | `formModel.bk_biz_id`（如表单默认值 931） | 服务请求下的 CVM 生产页 |

**适配方案**：给 `cvm-image-selector.vue` 新增可选的 `bizId` prop —— 父组件传入则用传入值，不传则 fallback 到全局 `getBizsId()`。`form-cvm-image-selector.vue` 作为包装层负责透传该 prop。

#### 功能点 2：私有镜像融入现有镜像列表

- **UI 无改动**：保持现有镜像选择器的原始外观和交互方式不变
- **数据融合**：将私有镜像数据合并到现有镜像列表中（与公共镜像混排或分组展示，取决于数据结构）
- **类型标识**：通过镜像数据的 `type` 字段区分 `PUBLIC_IMAGE` / `PRIVATE_IMAGE`，用于后续可能的标签展示

## 业务规则

### 数据来源
1. **业务 ID**：
   - 优先取父组件通过 `bizId` prop 传入的值
   - 未传 prop 时 fallback 到 `useWhereAmI().getBizsId()` 全局获取
   - 两种方式均无值时降级到旧接口（仅公共镜像）
2. **私有镜像列表**：调用后端接口 `POST /api/v1/woa/bizs/{bk_biz_id}/config/cvm/image` 按业务 ID 查询
3. 该接口同时返回公共镜像 + 该业务的私有镜像，前端无需额外聚合

### 兼容性要求
1. **零 UI 变更**：镜像选择器的外观、交互行为完全保持原样
2. **向后兼容**：非目标业务或无 bizId 时 fallback 到旧接口，行为与改造前一致
3. **多场景兼容**：同一套组件代码同时适配资源管理和服务请求两种上下文
4. 不影响其他表单项、提交流程、校验逻辑

## 输入与输出

### 输入
| 输入项 | 来源 | 说明 |
|--------|------|------|
| bk_biz_id | 父组件 prop 传入（可选） > `useWhereAmI().getBizsId()` | 当前业务 ID，来源灵活可配 |
| region | 当前表单选中地域 | 过滤该地域可用镜像 |

### 输出
| 输出项 | 格式 | 说明 |
|--------|------|------|
| 镜像列表 | `{ count, info: CvmImage[] }` | 包含公共镜像 + 条件性私有镜像 |
| 选中的镜像信息 | image_id + image_name + type | 提交到后端创建实例 |

## 边界场景

### 正常场景
1. 目标业务用户打开申领页 → 镜像列表中包含私有镜像选项
2. 用户选择私有镜像 → 表单正常提交
3. 用户切换地域 → 镜像列表随地域联动过滤（含私有镜像）

### 异常场景
1. **私有镜像接口请求失败** → 降级为仅显示公共镜像（fallback 到原有逻辑），不影响主流程
2. **业务 ID 为空** → 兜底不传业务参数或 fallback 到原有逻辑
3. **目标业务无可用私有镜像** → 仅显示公共镜像，无额外空状态提示（因为 UI 不变）

### 明确不改动的部分
- 镜像选择器的 UI 组件结构、样式、布局
- 表单其他字段的逻辑
- 主机申领/购买的提交流程
- 权限控制、校验规则等其他功能模块
