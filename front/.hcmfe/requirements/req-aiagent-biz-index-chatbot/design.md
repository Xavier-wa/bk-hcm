### 2.1 欢迎区

- 顶部居中：**AI 助手图标**（蓝色渐变云朵 + 闪光），使用指定资源 **`@/assets/image/cloud-assistant.svg`**（不走 iconfont / bkui）；其下欢迎语 **「海垒 AI 助手」**（加粗大字），再下功能 tips **「可使用对话进行快捷主机申领，主机回收，预测提单等」**（弱色小字）。

### 2.2 大卡片（响应式栅格）

- **响应式栅格**：列数随容器宽度自适应（如宽屏 2 列、窄屏 1 列），**卡片数量不写死**（由前端配置驱动）；**初始默认 4 张**（稿面 2×2）。
- 每张：左侧**图标**，右侧上下两行（**标题** + **描述**）。
- 初始卡片清单（标题 / 描述）：

| 位置 | 标题 | 描述 |
|------|------|------|
| 左上 | 申领 10 台主机 | 可通过智能推荐快捷申领主机 |
| 右上 | GPU 库存情况 | 可查看GPU库存情况及****（稿面文案被截断，以最终配置为准，见 Q-D1） |
| 左下 | 如何提交回收申请 | 可通过智能引导快速回收资源 |
| 右下 | 申领 50 台服务器 | 可通过智能推荐快捷申领服务器 |

- **Hover 态**：卡片出现边框高亮 / 轻微浮起（稿面左下卡片为 hover 示例），鼠标指针为可点击态。

### 2.3 小卡片 / 提示词（输入框上方一排，chip）

- 横向一排 chip，每个：小图标 + 短标签（场景名）。
- **响应式 + 分段翻页**：一排能放几个由容器宽度决定，放不下的通过行尾 `›`/`‹` **翻页**查看；**chip 数量不写死**（前端配置驱动）。
- chip **初始清单**（按稿面，共 **10 个**，顺序固定）：
  - 主机申领、主机回收、预测提单、预测调整、CLB申领、CLB删除、CLB批量导入、安全组创建、安全组规则管理、安全组绑定/解绑
  - 稿面在其默认宽度下首段展示前 8 个、第 2 段 2 个；**实际每段个数随宽度自适应**，8/2 仅为稿面默认示例，不写死。
- 行尾：**「›」分页箭头**（见 §3.4）。**不做**「换一批 / shuffle」（Q-D2 已确认）。
- **仅首页空态展示**；进入对话视图后整排隐藏（§3.3）。

### 2.4 输入框

- 占位 **「请输入问题，Shift + Enter 换行」**；左下角**附件（回形针）**图标；右下角**发送（纸飞机）**按钮。
- **发送按钮态**：输入框为空时**置灰**（不可发送）；有内容（含注入的场景 tag + 文本）时**高亮为蓝色**可发送。
- 输入框支持 **场景 tag（chip）前缀 + 自由文本** 混排；内容增多时**多行自适应增高**（稿面 note 3 示例：单行 → 多行 → 更多行）。
- 沿用现网 `ChatInput`（上一迭代已接入，组件支持 `TagSchema`），本迭代复用其 tag + 文本能力，不改其内部实现。

### 2.5 底部

- 居中弱色文案 **「有任何问题可联系 @小鲸手」**（@后人名以稿面为准）。

## 3. 关键交互

### 3.1 大卡片点击（直接发送）

- 点击任一大卡片 → **直接发送**该卡片对应的预设消息，立即创建会话并进入对话视图（等价于用户输入并发送）。
- 预设消息文案来源：前端固定配置（见 Q-D1：发送内容取卡片标题 还是 标题+描述拼接 还是独立 prompt）。

### 3.2 小卡片点击（统一：注入场景 tag + 默认词，待用户发送）

- 点击**任一**小卡片 → 在输入框注入**场景 tag**（如「主机申领」）+ 该场景的**默认提示词文案**（如「我要申请主机」），输入框激活、发送按钮变蓝。
- **所有小卡片行为一致**：**不自动发送**、**无「直达场景」特例**；用户可在默认词基础上继续编辑，再点**发送**触发（与 PRD §3.2 Q2 一致）。
- 场景 tag 在输入框内以 chip 形式展示在文本前；删除 tag / 文本规则沿用 `ChatInput`。
- 各场景默认文案来源：前端固定配置（见 Q-D1，api 阶段定稿）。

### 3.3 空态收敛

- 用户发送首条消息（含大卡片直发、或小卡片注入文案后点发送）或切换到已有会话后 → 主内容区切换为正常对话视图，欢迎区 + 大卡片 + 小卡片排**全部隐藏**。
- 「新对话」回到首页空态 → 重新展示欢迎区 + 大卡片 + 小卡片排。

### 3.4 小卡片「›」分页（Q-D2 已确认，稿面 note 2 细化）

- 行尾 **`›` 右箭头**：点击后快捷模版**整段滑动到下一段**，箭头**翻转为 `‹`**；再点 `‹` 回到上一段。
- 即**分段翻页**（segment 切换），非自由横向滚动、非「换一批」随机。
- **段数 / 每段个数由容器宽度 + chip 总数动态决定**（响应式）；当 chip 一排放得下时不展示分页箭头。稿面默认宽度下为 8 + 2 两段，仅示例。

### 3.5 输入框激活态（稿面 note 1 / note 3）

| 态 | 表现 |
|----|------|
| 空输入（未点卡片、未输入） | 占位文案展示；**发送按钮置灰** |
| 点小卡片后（任一） | 输入框出现**场景 tag chip** + 默认文案；光标在文本末；**发送按钮变蓝**；仍需用户点发送 |
| 用户继续输入 | tag 保留在前，文本在后；**多行自适应增高** |
| 进入对话视图 | 小卡片排隐藏（提示词不再展示） |

## 4. 状态流转

```
首页空态（无选中会话、无消息）
  → 展示：欢迎区 + 大卡片 2×2 + 小卡片(提示词)排
  → 点击大卡片 → 直接发送预设消息 → 创建会话 → 进入对话视图
  → 点击小卡片(任一) → 注入场景 tag + 默认文案，停留空态，待用户(可编辑后)点发送
  → 直接输入并发送 → 创建会话 → 进入对话视图
对话视图 → 点击「新对话」→ 回到首页空态（默认内容重新展示）
```

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 首页空态（未选会话、无消息） | 展示默认主内容区（欢迎区 + 大卡片 + 小卡片排） |
| 已有会话但**无消息**（选中了空会话） | 主内容区**保持空白**，不展示默认内容、不回退基础欢迎态（PRD §3.1 / §5 P1） |
| 已有会话有消息 | 正常对话视图 |
| 输入框为空 | 发送按钮**置灰**不可点 |
| 小卡片一排放得下（窄清单/宽容器） | 不展示 `›` 分页箭头（仅一段时） |
| 容器宽度变化 | 大卡片列数、小卡片每段个数**响应式重排**，初始默认按稿面 |
| 卡片为前端固定配置 | 无「无数据」分支；配置为空时该区域不渲染（理论兜底，不应发生） |
