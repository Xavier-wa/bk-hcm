## 2. UI 参照

### 现网参照

| 参照点 | 路径 / 组件 | 展示约定 |
|--------|-------------|---------|
| 实例配置机型行 | 主机申领表单「实例配置」卡片；`cvm-tip.vue` / `cvm-devicetype-selector` | `机型编码 (机型族, X核YG)`，如 `S5.LARGE8 (标准型, 4核8G)` |
| 推荐卡片键值表 | `host-apply-recommend-card.vue` + `host-apply-display.ts` | 仍为「机型」单行，**不新增**「机型族」「CPU」「内存」独立行 |

| 调整配置弹窗 | `host-apply-adjust-dialog.vue` 机型下拉 | 选项 label 附带规格；选中值仍为机型编码 |

### 展示格式（产品约束）

```
{device_type} ({device_family}, {cpu_core}核{memory}G)
```

示例：`S3.MEDIUM4 (标准型, 4核16G)`

规则：

- 机型族 = 配置中的机型族名称（`device_family`）
- 内存单位用「G」（与现网 tip 一致；参考图偶有「GB」写法，本迭代统一为 G）
- 部分规格缺失：有则拼接，缺失片段省略，不展示占位符
- 配置查不到 / 接口失败：仅展示原始 `device_type`
- `device_type` 为空：不展示机型行/列内容按现有空值逻辑（`--` 或过滤）

### 布局与交互

- **无新布局**：卡片壳、分页、按钮（选择方案 / 添加到配置清单）、表格列顺序均不变
- **无新图标**：本迭代不新增图标语义
- **加载体验**：可先展示原始编码，异步补全规格后更新同一单元格/同一行（不阻塞操作）
