# 实现策略

把设计语义翻译成目标项目已有的实现语言。Figma 图层嵌套和生成代码不需要一比一转换为 DOM 或组件树。

## 一、复用优先级

1. 目标项目已有业务组件和相邻封装。
2. 与项目版本严格匹配的组件 skill 确认过的 BlueKing 组件。
3. 语义 HTML/CSS 布局和业务组合。
4. 用户明确批准的最小手写组件。

普通 HTML/CSS 布局、页面容器和业务组合可正常实现，不需要手写组件许可。

## 二、组件决策

| 情况 | 决策 |
| --- | --- |
| 相邻代码已有业务封装 | 优先复用，确认扩展点是否足够 |
| 版本 map 有对应组件 | 路由到匹配组件 skill，读取目标 reference 后组合 |
| Figma 图层名与组件同名 | 仅作为候选，仍按行为和 API 复核 |
| 组件外观不同但行为一致 | 优先用公开 props/slots 定制 |
| 静态 map 未命中 | 搜索对应组件 skill 的完整索引和同义语义 |
| 组件 skill 仍未命中 | 列出检索范围和能力缺口，询问是否允许手写 |
| 用户批准手写 | 只实现填补能力缺口所需的最小组件 |

组件候选固定路由：

| 组件库 | 组件 skill |
| --- | --- |
| `bk-magic-vue` / Vue2 | `bk-magicbox-vue-components` |
| `bkui-vue` / Vue3 | `bkui-vue-components` |
| `@blueking/tdesign-ui` | `blueking-tdesign-ui` |
| `@blueking/search-select-v3` | `blueking-search-select-v3` |
| `@blueking/date-picker` | `blueking-date-picker` |

对每个候选，从对应组件 skill 的索引定位并读取目标 reference，确认 props、events、slots、methods、类型、默认值、限制和示例。组件 API 以该 reference 为最终依据；项目相邻代码只用于业务封装、导入方式和编码风格。不得让安装源码、类型声明、其他版本文档、Figma 参考代码或记忆在冲突时胜出。

组件 skill 不可用或 reference 缺失时，说明兼容性阻塞并停止，不得用手写规避文档缺失。完整索引可用但没有组件能力覆盖设计时，必须说明已检索的 skill、索引、组件候选和能力缺口，并询问用户是否允许手写；未获批准不得实现替代组件。

## 三、样式与 Token

| 证据 | 落地方式 |
| --- | --- |
| 项目已定义、加载并使用语义 Token | 使用该 Token |
| 项目有 Sass/CSS/utility 体系但无对应 Token | 按现有局部写法使用设计值 |
| 只有 Figma variable 名称 | 先核对项目，不直接输出同名变量 |
| 候选 Token 数值接近但语义不同 | 不强行映射 |
| 单次特殊值 | 保持局部，不升级为全局 Token |

不得为一个组件新增全局 Theme provider、utility preset 或 Token 系统。响应式沿用项目断点和设计 variants；两者都没有依据时先问，不自行发明断点。

## 四、Icon 与资源

1. 复用项目中造型和语义都匹配的现有资源。
2. 使用项目已接入 Icon 包的真实 export。
3. 没有匹配项时，从 Figma 获取真实 SVG/图片并遵循资源目录、命名和 barrel 约定。

最终代码不得使用 emoji、占位 path、占位图片、近似 CSS 图形或语义不符的图标。

## 五、文案、数据和可访问性

- 遵循项目 i18n；相邻代码已本地化时不硬编码可见文案。
- 不从示例数据反推接口结构，数据契约以项目代码和需求为准。
- 原生交互优先使用 button、a、input 等正确语义。
- 可点击 Icon 需要按钮语义和可访问名称。
- 表单 label、错误提示、焦点顺序和键盘操作沿用项目规范。

## 六、范围控制

只实现请求的设计和有依据的状态，不顺带：

- 重构无关代码。
- 新增通用配置或未来能力。
- 设计未要求的 props、状态和交互。
- 为单个使用方创建抽象层。
- 更换项目已有设计系统。

## 七、常见错误

| 错误 | 正确处理 |
| --- | --- |
| 复制 Figma 生成代码 | 只取结构、变量和视觉信息，转换到项目原生实现 |
| 图层逐层生成容器 | 按语义和布局需要组织 DOM |
| 根据组件名或安装源码猜 props | 从配套组件 skill 的目标 reference 确认 |
| map 未命中就直接手写 | 搜索组件 skill 完整索引；仍未命中则列出缺口并询问 |
| 看到 Figma Token 就写 `var(--xxx)` | 先证明项目已接入 |
| 找不到 Icon 就用近似图标 | 获取真实资源或询问 |
| 为“完整性”补空态/错误态 | 只实现有依据的状态 |
