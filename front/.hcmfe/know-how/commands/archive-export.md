归档导出：使用 `git archive` 导出指定目录的受版本控制文件（自动遵循 `.gitignore`）。参数: `$ARGUMENTS`

## 参数说明

- 第一个参数：要导出的目录（相对仓库根目录），默认 `front`
- 第二个参数：导出格式，`zip`（默认）或 `tar.gz`
- 第三个参数：输出文件路径，默认 `./<目录名>.<格式后缀>`
- `--ref=<tree-ish>`（可选）：导出的提交引用，默认 `HEAD`，可指定分支名或 Commit ID

## 执行步骤

### 1. 解析参数

使用**选择器**让用户确认（而非手动输入）：

- **导出目录**：默认 `workspaceFolder` 下的 `front` 目录；提供选项 - `front`（推荐）或自定义路径
- **导出格式**：提供选项 - `zip`（推荐）或 `tar.gz`
- **导出引用（ref）**：提供选项 - `HEAD`（当前分支最新提交，推荐）、指定分支或 Commit ID
- **输出路径**：默认 `./<目录名>.<格式后缀>`（如 `./front.zip`），允许自定义

### 2. 校验目录

确认目标目录在指定 ref 下存在且受版本控制：

- 执行 `git ls-tree <ref> <目录>/` 检查目录是否存在于版本库
- 若目录不存在或无受控文件，提示用户并让其重新选择目录

### 3. 执行导出

使用 `git archive` 导出指定目录子树。通过 `<ref>:<目录>` 树对象语法只打包该子目录内容：

- **zip 格式**：
  `git archive --format=zip --prefix=<目录>/ --output=<输出路径> <ref>:<目录>`
- **tar.gz 格式**：
  `git archive --format=tar.gz --prefix=<目录>/ --output=<输出路径> <ref>:<目录>`

**说明**：

- `<ref>:<目录>` 表示导出该提交下指定子目录的文件树，归档内路径相对于该子目录
- `--prefix=<目录>/` 保留目录名作为归档内的顶层目录前缀，解压后结构与仓库一致
- `git archive` 只包含受版本控制（已 track）的文件，自动遵循 `.gitignore`，不包含未跟踪文件

### 4. 确认结果

导出完成后：

- 执行 `ls -lh <输出路径>` 展示生成的归档文件大小
- 向用户输出归档文件的绝对路径，提示导出成功

## 注意事项

- `git archive` 仅导出**已被版本控制**的文件；未跟踪的新文件（即使未被 gitignore）不会包含在内，导出前请确认相关文件已 commit
- 建议在代码合并完成并提交后再执行导出，确保归档内容为最新合入状态
- 默认 `HEAD` 导出当前分支最新提交，如需导出特定分支或历史版本，请通过 `--ref` 指定
