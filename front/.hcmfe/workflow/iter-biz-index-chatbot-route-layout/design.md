# Design：业务视角首页 chatbot - 路由与布局

## 0. 本子需求范围（Design 阶段约束）

**仅交付：路由 + 页面布局实现。**

| 在本子需求内 | 不在本子需求内 |
|--------------|----------------|
| 顶栏「资源管理」入口、`/business/index` 路由 | 新 Agent / 新后端接口 |
| 权限入口（`chatbot_access`）与无权限页 | `/chatbot` 旧链兼容 |
| 页面壳层：顶栏 + **左侧业务菜单（常显）** + 会话侧栏 + 主对话区 | 对话/HITL/流式 **新功能**（嵌入既有组件即可） |
| 会话侧栏 **展开 / 收起** 两种布局态（对齐 Figma） | 隐藏业务菜单、全屏独占 chatbot |

## 2. 信息架构与导航

### 2.1 顶栏（全局 Header）

| 变更前（现状） | 变更后 |
|----------------|--------|
| 「首页」→ `/chatbot` | **移除** |
| 「资源管理」→ `/business/host` | **保留唯一**「资源管理」→ `/business/index` |
| 其它 tab 不变 | 服务请求、资源接入等保持 |

**有 `chatbot_access`**：展示「资源管理」tab。  
**无权限**：不展示「资源管理」tab。

**高亮**：路由为 `/business/index` 或 `/business/index/:sessionCode` 时，「资源管理」为选中态。

### 2.2 路由与 URL

| 路径 | 含义 |
|------|------|
| `/business/index` | 业务 AI 首页 |
| `/business/index/:sessionCode` | 指定会话 deep link |

不保留 `/chatbot`；无旧链跳转。URL 继续带 query **`bizs`**（`GLOBAL_BIZS_KEY`）。

### 2.3 左侧业务菜单

| 场景 | 左侧业务资源树（主机/VPC/…） |
|------|------------------------------|
| `/business/host` 等 | **展示** |
| **`/business/index`（本页）** | **同样展示**（与业务视角其它页一致，不隐藏） |

业务菜单与 chatbot 内容区 **并列**：菜单占固定宽度，右侧为 chatbot 双栏（会话侧栏 + 主对话区）。

## 3. 页面布局（内容区）

参考 Figma **`2006-6056`（展开）** 与 **`2031-829`（会话侧栏收起）**。

```
┌──────────────────────────────────────────────────────────────────┐
│  全局顶栏：Logo | 资源管理(选中) | 服务请求 | ... | 用户/业务选择  │
├──────────┬──────────────┬────────────────────────────────────────┤
│ 业务菜单  │ 会话侧栏      │  主对话区                               │
│ (常显)   │ (可收起)     │  ┌────────────────────────────────────┐ │
│ 主机     │ [开启新对话]  │  │ 页内标题：当前会话名                  │ │
│ VPC      │ 置顶/今天/…  │  ├────────────────────────────────────┤ │
│ …        │ [收起]       │  │ 消息区 / 空态 / 加载态                │ │
│          │              │  ├────────────────────────────────────┤ │
│          │              │  │ 输入区                               │ │
│          │              │  └────────────────────────────────────┘ │
└──────────┴──────────────┴────────────────────────────────────────┘
         ↑ 2031-829：会话侧栏收起后，主对话区变宽，业务菜单仍保留
```

### 3.1 业务菜单区（左一，常显）

- 与现有 `/business/*` 资源页 **同一套** 左侧导航（主机、VPC 等入口可点跳转）。
- 当前页为「资源管理」首页时，菜单高亮/选中规则与产品约定一致（以实现为准，不要求新增菜单项）。

### 3.2 会话侧栏（左二，chatbot 专用）

对齐 **`2006-6056`（展开）** / **`2031-829`（收起）**：

| 元素 | 说明 |
|------|------|
| 开启新对话 | 主操作按钮 |
| 会话列表 | 分组：置顶、今天、昨天、7 天内、30 天内、更早 |
| 会话项 | 选中高亮；更多：重命名、置顶、删除 |
| **收起侧栏** | 切换至 **`2031-829`** 布局：侧栏收窄/仅保留展开触发，**不占用业务菜单区域** |
| 展开侧栏 | 从收起态恢复至 **`2006-6056`** |

交互细节（重命名、删除确认等）沿用既有 chatbot 实现；本子需求只保证 **两种布局态** 与间距、宽度符合稿。

### 3.3 主对话区（右）

| 区域 | 说明 |
|------|------|
| 页内标题 | 当前会话名称 |
| 消息区 | 嵌入既有 MessageContainer 等；空态/加载态占位对齐 Figma |
| 输入区 | 底部固定；对齐稿面间距 |

**消息锚点**等非稿面元素：不纳入本子需求必达项；若现网已有可保留，不以本 design 为准。

## 4. 关键流程（布局相关）

### 4.1 进入

顶栏「资源管理」→ `/business/index?bizs=...` → 展示 **业务菜单 + chatbot 双栏**（默认展开态 `2006-6056`）。

### 4.2 收起 / 展开会话侧栏

- 收起 → 布局切换为 **`2031-829`**，主对话区变宽；业务菜单不变。
- 展开 → 恢复 **`2006-6056`**。

### 4.3 切换业务（query `bizs`）

更新 URL query `bizs`；业务菜单随业务切换。本迭代 **Agent 会话数据不按 biz 分隔**（接口未变，见 `api.md`）；布局结构不变。

### 4.4 无权限直访

全页权限申请页，不展示上述三栏布局。

## 5. 权限与异常态

| 场景 | 展示 |
|------|------|
| 有权限 | 顶栏 + 业务菜单 + chatbot 双栏 |
| 无权限，顶栏 | 无「资源管理」 |
| 无权限，直访 URL | 权限申请页 |
| `/chatbot` | 不注册路由，无兼容跳转 |
