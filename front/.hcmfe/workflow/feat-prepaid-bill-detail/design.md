## 3. 关键交互

### 3.1 进入与返回

- 列表预付费 ID 进入 `/bill/prepaid/detail/:id`（路由已有）。
- 返回走全局面包屑 back，回到预付费列表，保留列表筛选/分页 query（现网返回惯例；coding 对齐相邻详情）。
- 无新增、编辑、删除、导出、重试按钮。

### 3.2 只读展示

- 基本信息全部只读，无复制按钮要求（稿面未画）。
- 资源 ID 过长：稿面折行，落地允许折行，不强制截断。
- 整合表只读；账期、调账金额表头排序仅对**当前已加载的明细行本地排序**（分摊查询无请求体，不另传 sort）。默认顺序跟接口返回。

### 3.3 整单核算摘要

| 单据状态 | 核算状态 | 累计核算金额 |
|----------|----------|--------------|
| 已定账 | 真实三态 Tag：待核算 / 核算中 / 已完成 | 真实金额，主橙加粗 |
| 未定账 | `--` | `--` |

已定账且「已完成」跟稿：success 绿底 Tag。核算中用 info Tag。待核算无 theme。

### 3.4 行级核算与调账类型

- 已核算：绿圆点 + 「已核算」。
- 未核算：灰圆点 + 「未核算」。
- 调账类型文案跟 PRD：增加 / 减少（稿面「增加 / 调减」→ **减少**）。列用 `dynamic-tag-status`：增加 success、减少 danger。
- 调账金额：绝对值、右对齐、无正负号。正负由类型列表达（与金额一律为正的数据口径一致）。用户已确认跟稿。

### 3.5 失败原因

稿面无失败区块。主表无失败态则不画。若主数据带来失败原因：展示在标题区 Tag 下方或基本信息卡片之上，纯文本，无重试。

## 4. 状态流转

```text
从列表点预付费 ID / 直链
  ├─ 无查看权限 → 不展示该账单（藏菜单规则同列表；直链不走申请页）
  ├─ 越权（他人账单）→ 不渲染主信息与分摊表
  └─ 有权
        ├─ 拉主数据 + 分摊明细（可并行）
        ├─ 主数据失败 → 提示，不画成功空壳
        ├─ 已定账 → 摘要真实值 + 表
        ├─ 未定账 → 摘要 -- + 表仍展示行级核算
        └─ 无分摊行 → 空表（卡片与摘要仍在）
返回 → 面包屑 back 回列表
```

无轮询、无重试按钮、无行点击下钻。

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 越权直链 | 不展示他人字段与分摊明细 |
| 主数据查询失败 | 错误提示；可返回列表；不渲染错误数据 |
| 分摊查询失败 | 基本信息仍可展示（若主数据成功）；表明失败提示；不虚构行 |
| 无分摊行 | 表空态（`Exception` scene=part / 表格 empty） |
| 发票 ID 空 | `-` |
| 备注空 | 空或 `-`（跟列表空值习惯） |
| 未定账 | 摘要两项 `--`；表照常 |
| 失败原因（若有） | 只读说明，无重试 |
| 超过 37 行 | 产品约定不超过；若返回更多仍单页渲染，可纵向滚动，仍不分页 |

稿面未提供 loading / 未定账 / 空表 / 失败独立画板。loading 用现网 `v-bkloading` 盖卡片。
