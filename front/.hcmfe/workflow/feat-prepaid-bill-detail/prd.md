## 背景

账号负责人需要从预付费列表下钻到单笔账单，核对订单、资源、金额与使用周期是否与云上一致，并按月查看分摊金额、对应调账编号、该月是否已进入 OBS 核算。页面全部只读。

本迭代只交付详情主信息与分摊/调账整合表，不交付列表改造、导出、账单调整页改造。

## 用户故事

作为 二级账号负责人
我想要查看单笔预付费账单的全量字段（只读）
以便于核对订单、资源、金额与使用周期是否与云上一致。

作为 二级账号负责人 / 产品财管
我想要在详情页看到按月分摊行与关联调账的整合表，并知道每一行是否已核算
以便于定位哪一个月的分摊还没进入 OBS。

## 需求点

1. 从预付费账单列表点击预付费 ID，进入该笔账单的只读详情页；详情页提供返回列表。
2. 页面只读：无新增、无编辑、无删除、无导出、无失败重试、无人工确认/驳回。
3. 权限与「预付费管理」列表相同（二级账号查看）。越权访问他人账单详情时，不展示该账单字段，也不展示分摊明细。
4. 详情页主内容区按稿分为：标题区（返回 + 标题 + 单据状态）、基本信息卡片、分摊与调账明细卡片。无页内编辑控件。
5. 主信息展示与列表一致的 22 项字段，均为只读。字段依次为：预付费 ID、订单月份、资源 ID、运营产品、二级账号名称、一级账号名称、GPU 型号、数量(台)、数量(卡)、优惠后总价(不含税)、累计核算金额、核算状态、币种、产品名称、产品规格、Region、使用开始时间、使用结束时间、订单时间、发票 ID、云厂商、单据状态。
6. 稿面分区：
   - 标题区：返回列表；标题文案以「预付费详情」为准；单据状态以 Tag 展示在标题旁
   - 基本信息三列：预付费 ID、订单月份、资源 ID、运营产品、一级账号名称、二级账号名称；GPU 型号、数量(台)、数量(卡)、优惠后总价(不含税)（币种跟在金额后，不单独占格）、产品名称、产品规格；Region、订单时间、使用开始时间、使用结束时间、发票 ID、云厂商
   - 分摊与调账明细：卡片顶部为整单核算状态、累计核算金额；下方为整合表
7. 整单核算摘要在分摊模块顶部，按单据状态遮蔽，与列表「始终展示真实值」不同，仅作用于本详情页：
   - 已定账：展示真实核算状态与累计核算金额
   - 未定账：两项均展示 `--`
8. 整单核算状态文案与列表一致：待核算 / 核算中 / 已完成。
9. 若主数据带有失败原因，则在详情中展示失败原因，且不提供重试入口。主表单据状态本期仅未定账 / 已定账（与列表迭代已对齐的后端口径一致）；无失败态时不出现失败原因区块，也不新增第三种单据状态。
10. 分摊与调账明细为只读表，一页展示完、不分页。列依次为：调账编号、账期、核算状态、调账类型、调账金额、备注。
11. 行级核算状态仅两态：已核算 / 未核算。该行对应分摊已进入 OBS 核算则为已核算，否则为未核算。与整单核算三态文案不同，不可混用。
12. 调账类型为增加 / 减少。调账金额按绝对值展示（不带正负号），增减语义只由调账类型表达；金额本身不做隐私脱敏。
13. 整合表按月展示分摊行；订单月的全额调减单独成行，账期为订单月份，类型为减少。
14. 整合表最多 N+1 行（N≤36，即不超过 37 行）。无分摊行时展示空表，不虚构行。
15. 金额、账号、资源等主信息字段不做脱敏。
16. 查询失败时提示错误，不渲染他人数据或错误全量；不把失败结果展示成空白成功页。

## 单据状态与核算口径

- 单据状态（整单）：未定账 / 已定账。
- 整单核算状态：待核算 / 核算中 / 已完成（仅已定账时在分摊模块顶部展示真实值）。
- 行级核算状态：已核算 / 未核算。

## 验收标准

- AC-014：从列表点击预付费 ID 进入详情，展示与列表一致的 22 项字段且均为只读。
- AC-015：单据状态=已定账时，分摊模块顶部的核算状态、累计核算金额展示真实值。
- AC-016：单据状态=未定账时，分摊模块顶部的核算状态、累计核算金额均为 `--`。
- AC-017：订单月=2026-07、分摊覆盖 2026-08/09/10 时，整合表共 4 行：3 行增加 + 1 行减少（减少行账期=2026-07）。
- AC-018：仅 2026-08 分摊已进入 OBS 核算时，08 行为已核算，其余行为未核算。
- AC-019：主数据若带失败原因，详情可见失败原因且无重试入口；无失败态则本条不适用。
- AC-020：仅有账号 M1 权限时直接打开 M2 账单详情，不展示 M2 字段与分摊明细。
- AC-P03：整合表不超过 37 行时，主信息与整合表均可在数据返回后立即完整看到，无需翻页。
- AC-D01：主内容区含标题区、基本信息、分摊与调账明细；有返回列表。
- AC-D02：整合表六列齐全且只读；无行时为空表。
