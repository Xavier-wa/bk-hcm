## 1. 背景与目标

智能助手一轮回复里会穿插多次「已思考完成」和「调用工具: xxx 调用成功」。现状是每次工具调用都单独铺开完成态，用户看不到本轮整体进度；过程条、中间说明和最终正文/卡片也缺少统一视觉分组。

**目标**：把同一轮思考与工具调用收成可展开/收起的过程区，结束后收成一行摘要，最终结论始终露出；同一轮共用浅底；工具行改稿面外观，并在上方展示 `tool-intent` 说明。全页 chatbot、浮窗与历史回放同一套。

## 2. 用户故事

- US-1 作为智能助手使用者，我想要把一轮回复的思考与工具调用收成一行摘要，需要时点开看全过程，以便看到整体进度而不是每次工具都铺开完成态。
- US-2 作为智能助手使用者，我想要同一轮助手回复有统一浅底，以便把过程、中间说明和最终结论识别成一条回答。
- US-3 作为智能助手使用者，我想要在工具行上方看到 `tool-intent` 说明（历史回放也在上方），以便理解这次调用在做什么。

## 4. 功能需求

| 编号 | 需求点 | 优先级 |
|------|--------|--------|

| F-002 | 流式中过程区默认展开；正常结束或非用户停止的中断后自动收起；历史回放按已结束处理，默认收起 | P0 |
| F-003 | 点击摘要行切换展开/收起；不做独立「展开全部 / 收起」按钮 | P0 |

| F-005 | 现有工具行改稿面样式；说明取自该次调用参数 `tool_intent`，单独一行画在对应工具行上方；`/agui` 与 `/history` 同一套拆分 | P0 |
| F-006 | 摘要：有工具写 `调用N个工具，思考耗时X.XXs`；仅思考写 `思考耗时X.XXs`；单位小写 `s`、两位小数 | P0 |
| F-007 | 全页 chatbot、浮窗 `ai-assistant`、历史回放同一套行为 | P0 |

## 5. 业务规则

- **R-001** 收起只收过程（思考 + 工具），不收最终正文/卡片/表格，也不收工具之间的中间说明。
- **R-002** 展开/收起唯一入口是摘要行。
- **R-003** 流式中展开；正常结束 / 异常中断 / 历史默认收起；用户点「停止生成」保持当时展开态，摘要按已发生内容结算。
- **R-004** 耗时单位小写 `s`，两位小数（如 `8.14s`、`0.29s`）；优先协议 duration，缺省前端计时。
- **R-005** 无工具时不要「调用 0 个工具」；无思考且无工具则不渲染过程区。
- **R-006** 说明来自工具参数 `tool_intent`；画在对应工具行上方，不再单独占助手气泡；缺字段或文案为空则只保留样式化工具行。旧 `TEXT_MESSAGE_CHUNK` / history `tool-intent-{toolCallId}` 不再用于取数。
- **R-007** 工具行内部详情沿用现有组件（如 `@blueking/chat-x` `ToolcallRender`），不新做完整入参/出参面板。
- **R-008** 前端不做工具名中文映射；不要求后端改 `/history` 顺序或补字段。

## 6. 协议约定（产品视角）

不新增 HTTP 接口。工具说明取自已有 AG-UI / history：

**`/agui`**：`TOOL_CALL_START` → `ARGS`（JSON 含 `tool_intent`）→ `END` → `RESULT`。说明从该次调用自己的参数取出。

**`/history`**：带 `toolCalls` 的助手消息里，各 `function.arguments.tool_intent` 即该行说明。旧快照里若仍有平级 `id: tool-intent-{toolCallId}` 消息，丢弃即可。

## 7. 验收标准

| ID | Given | When | Then |
|----|-------|------|------|
| AC-001 | 一轮回复含多次思考与工具调用 | 本轮正常结束 | 过程区自动收起，摘要为 `调用N个工具，思考耗时X.XXs`，最终正文/卡片仍可见 |
| AC-002 | 过程区已收起 | 点击摘要行，再点同一行 | 先展开全过程，再收起；结论始终可见 |
| AC-003 | 本轮正在流式输出 | 尚未结束 | 过程区保持展开，能看到当前思考与工具进度 |
| AC-004 | 用户中途点「停止生成」 | 流式中断 | 过程区保持展开，摘要按已发生工具数与已思考时长结算 |
| AC-005 | 本轮只有思考没有工具 | 结束后收起 | 摘要为 `思考耗时X.XXs`，不出现「调用 0 个工具」 |
| AC-006 | `/agui` 的 `TOOL_CALL_ARGS` 含 `tool_intent` | 渲染该次工具调用 | 说明在工具行上方单独一行；详情「参数」不再出现 `tool_intent`；工具行为稿面样式；不另出助手气泡 |
| AC-007 | `/history` 助手消息一条带 N 个 `toolCall`，各自 arguments 含 `tool_intent` | 回放该轮 | 每条工具行上方是**自己那句**说明，不糊成一段 |
| AC-007b | 没有 `tool_intent` 或文案为空 | 渲染该次工具调用 | 不出现说明行，仅保留样式化工具行 |
| AC-008 | 一轮含过程、中间说明与卡片 | 展示 | 它们落在同一块浅底内；用户气泡与相邻轮次不套入 |
| AC-009 | 全页或浮窗打开历史会话 | 回放已结束的一轮 | 过程区默认收起，点摘要行可展开，行为与新回复一致 |
| AC-010 | 展开某次工具调用 | 查看内部详情 | 仍是现有组件交互，不是新做的完整入参/出参面板 |
| AC-P01 | 点击摘要行 | 展开或收起 | 100ms 内完成，不发起新的会话接口 |
| AC-S01 | 无 `agent_assistant` | 访问入口 | 行为与现网一致，不新增权限点 |
