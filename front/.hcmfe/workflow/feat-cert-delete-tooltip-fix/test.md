# test - 证书-删除按钮tooltip错误

## 前置
- 进入「证书管理」页面，分别用**资源运营（资源视角）**与**业务视角**验证。

## P0 用例

### P0-1 资源视角 + 已分配业务的证书
- 数据：资源运营视角下，`bk_biz_id !== -1` 的证书。
- 操作：悬停「删除」按钮。
- 期望：按钮为禁用态（灰），悬停弹出 tooltip「该证书已分配业务, 仅可在业务下操作」。

### P0-2 资源视角 + 未分配业务的证书
- 数据：资源运营视角下，`bk_biz_id === -1` 的证书。
- 操作：悬停「删除」按钮。
- 期望：按钮可点（非禁用）；**不显示**任何「已分配业务」相关 tooltip。

### P0-3 业务视角
- 数据：业务视角下任意证书。
- 操作：悬停「删除」按钮。
- 期望：按钮可点（有删除权限时）；不显示「已分配业务」tooltip（该文案仅资源视角业务归属场景适用）。

## P1 用例

### P1-1 删除流程未受影响
- 资源视角 + 未分配业务的证书，点击「删除」→ 应弹出删除确认框，流程与修复前一致。

### P1-2 无权限场景
- 无删除权限时按钮禁用；tooltip 不显示（文案仅描述业务归属，与权限无关，属预期）。
