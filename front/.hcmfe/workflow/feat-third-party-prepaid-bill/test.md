# feat-third-party-prepaid-bill 测试清单

> 工作流: `feat-third-party-prepaid-bill`
> 关联文档: PRD / Design / API / Coding
> TAPD: 预付费账单列表查询展示 `1069995598137371362`

## 验证范围

- 功能边界: 资源运营下独立「预付费管理」列表：跨账期筛选、22 列只读展示、分页排序、菜单权限。
- 不在范围: 导出按钮行为（见 feat-prepaid-bill-export）；详情页内容（见 feat-prepaid-bill-detail）；账单调整列表守卫（见 feat-bill-adjust-guard）；新增/编辑/删除。

## 测试环境

- 前端入口: `<对应业务的测试环境地址，由执行人在测试时确认；不要把具体域名写入仓库>`
- 测试账号: `<test_account>`（敏感信息用占位符，不写真实账号）
- 数据准备:
  - 至少 1 个有预付费数据的二级账号、至少 1 条未定账与 1 条已定账账单
  - 覆盖不同订单月份、不同运营产品的多条记录（建议 ≥ 3）
  - 一个无任何二级账号授权的非管理员账号（空态）
  - 一个仅授权部分二级账号的账号（行级隔离）
  - 查询失败可用浏览器拦截 `POST /api/v1/account/bills/prepaid_items/list` 返回 500

## 用例清单

### P0 - 主流程（必测）

| ID | 场景 | 前置 | 操作 | 期望 | 回滚 |
|----|------|------|------|------|------|
| P0-01 | 打开独立预付费列表 | 账号具备二级账号查看权限 | 资源运营 → 云账单管理旁进入「预付费管理」 | 独立列表页，无固定账单月份选择器；无新增/编辑/删除 | 无需 |
| P0-02 | 默认筛选与高级筛选 | 已进入列表 | 查看基础区；展开高级筛选 | 基础：使用时间、运营产品、二级账号名称。高级：一级账号、GPU 型号、产品名称、云厂商、订单月份。无「订单时间」范围筛 | 收起高级 |
| P0-03 | 空条件分页查询 | 权限范围内有数据 | 不填筛选直接查询 | 返回权限范围内数据并分页；默认按订单时间从新到旧 | 无需 |
| P0-04 | 使用时间按日闭区间 | 至少 1 条使用周期与所选日重叠的账单 | 选同一天为起止日后查询 | 按开始日 00:00:00、结束日 23:59:59 生效；命中重叠账单 | 清空日期 |
| P0-05 | 订单月份闭区间 | 存在 2026-07 / 08 / 09 订单月数据（或当前环境等价三个月） | 高级筛选选起止月份后查询 | 含首尾月；列表「订单月份」为 `YYYY-MM`，取值来自 `order_at` | 清空月份 |
| P0-06 | 22 列只读齐全 | 列表有数据 | 横向滚动查看全部列 | 列依次为：预付费 ID、订单月份、资源 ID、运营产品、二级账号名称、一级账号名称、GPU 型号、数量(台)、数量(卡)、优惠后总价(不含税)、累计核算金额、核算状态、币种、产品名称、产品规格、Region、使用开始时间、使用结束时间、订单时间、发票 ID、云厂商、单据状态；无失败原因列 | 无需 |
| P0-07 | 预付费 ID 进入详情 | 列表至少 1 行 | 点击预付费 ID | 进入 `/bill/prepaid/detail/:id`；本单不验收详情字段 | 返回列表 |
| P0-08 | 未定账核算不遮蔽 | 至少 1 条未定账账单 | 定位该行 | 累计核算金额、核算状态展示真实值，不是 `--`；无失败原因 | 无需 |

### P1 - 异常分支（必测）

| ID | 场景 | 前置 | 操作 | 期望 |
|----|------|------|------|------|
| P1-01 | 使用时间起止不合法 | 进入列表 | 开始日晚于结束日后查询 | 提示不合法，不发出有效列表请求，筛选保留 |
| P1-02 | 订单月份起止不合法 | 展开高级筛选 | 开始月晚于结束月后查询 | 提示不合法，不发出有效列表请求 |
| P1-03 | 列表接口失败 | 拦截 `prepaid_items/list` 返回 500 | 触发查询 | Toast/错误提示，列表不被错误全量覆盖；可重试 |
| P1-04 | 无授权空态 | 非管理员且无任何二级账号授权 | 打开预付费管理 | 空态，不是权限申请整页，也不是全量数据 |
| P1-05 | 行级隔离 | 仅授权账号 M1 | 查询 | 只出现 M1 数据，不含未授权账号 |

### P2 - UI 细节（按需）

- [ ] 使用时间 datepicker placeholder 为「请选择日期」
- [ ] 订单月份 monthrange placeholder 为「请选择月份」
- [ ] 账号/运营产品选择器按名称展示，请求按 ID 生效
- [ ] 多条件同时生效（AND），不是任一命中
- [ ] 无 `main_account_find` 时侧栏隐藏「预付费管理」；直链不进申请页，由接口鉴权
- [ ] 单页条数不超过 500，默认页大小与现网列表一致
- [ ] 金额不做脱敏
