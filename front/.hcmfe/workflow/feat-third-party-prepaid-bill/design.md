## 3. 关键交互

### 3.1 入口与权限

- 点击侧栏「预付费管理」进入本列表。
- 无云账单查看权限：现网同一套权限申请页，不渲染列表。
- 非管理员且无任何二级账号授权：进入列表页，表格空态（筛选区仍在），不是整页申请权限。

### 3.2 筛选（逻辑以 TAPD 为准）

需求单 F-FE-002 / AC-002～006 / AC-014 已定义，本期照做：

| 筛选项 | 控件（现网 Search） | TAPD 规则 |
|--------|---------------------|-----------|
| 使用时间 | 日期范围（只到日，无时分秒） | 开始日 ≤ 结束日；请求补开始日 `00:00:00`、结束日 `23:59:59` |
| 运营产品 | 选择器 | 与其它条件 AND |
| 二级账号名称（基础）/ 一级账号名称（高级） | 账号选择器（展示名称） | 请求传账号 ID，不按名称字符串匹配 |
| GPU 型号 / 产品名称 / 云厂商 | 与现网同类筛一致 | AND |
| 订单月份（高级） | 起止月份 | `YYYY-MM` 闭区间，开始月 ≤ 结束月；**不是**「订单时间」范围筛 |

其它 TAPD 边界：

- 基础三项默认展示；高级五项折叠，点击展开。
- 筛选全空：查权限范围内全部（仍分页）。
- 多条件同时生效，关系为 AND。
- 参数非法：提示错误，保留当前筛选，不清空成全量。
- 接口失败：提示失败，列表保持上次成功结果或空表，可重试。
- 筛选变更后等接口返回再渲染，不额外轮询。

顶部搜索与表头漏斗是两套入口：Search 管需求单那批条件并请求接口；漏斗只管稿面标了漏斗的列，**按当前页本地筛选、先不按接口**。漏斗不替代 Search，也不还原稿面八宫格。

### 3.3 表头排序与列头筛选（交互以稿面为准）

**策略（用户确认）**：UI 交互先按稿面做；列表请求带上对应 sort / filter。联调时若接口不支持，再收口（关掉该列交互或降级提示），不在 design 阶段因接口未定砍掉稿面。

**默认排序（需求单仍有效）**：首次进入、用户未点任何列头时，按 **订单时间倒序**（F-FE-002 / AC-015）。点了可排序列后，以该列单列排序为准（升序 / 降序切换，现网表格常见交互）。

## 4. 状态流转

```text
进入页
  ├─ 无视图权限 → 权限申请页（结束）
  └─ 有权限
        ├─ 拉 Search 默认 / URL 条件；表头未操作时订单时间倒序 → 请求列表
        ├─ 点漏斗 → 只筛当前页，不重发 list
        ├─ 有数据 → 表 + 分页
        ├─ 无授权账号（非管理员）→ 空表
        ├─ 筛选无命中 → 空表（筛选仍在）
        └─ 点预付费 ID → 详情路由（本期可空页）
```

无新增、无行内编辑、无失败重试。改 Search 后重新请求列表；点漏斗只筛当前页、不重发 list。Search 非法条件不发有效请求。
