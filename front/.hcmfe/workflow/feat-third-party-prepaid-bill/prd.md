# PRD — 预付费账单列表查询展示

> 来源：TAPD story `1069995598137371362`（全量解读 + 两轮澄清）
> 父需求：三方云预付费账单管理-前端 `1069995598137371319`
> 单据：https://<TAPD_HOST>/tapd_fe/69995598/story/detail/1069995598137371362

## 背景

现网「云账单管理」以固定账单月份为查询前提，无法承载跨多个自然月的三方云预付费账单。财务、账号负责人需要独立的「预付费管理」入口，按使用周期跨账期只读查询账单，并看到单据状态与核算进度。

本迭代只交付前端列表主入口，不交付导出、详情内容、账单调整页改造。

## 用户故事

作为 二级账号负责人
我想要跨账期筛选并查看自己权限范围内的预付费账单列表
以便于核对本账号的成本归属，而不必按固定账单月份逐月翻页。

作为 产品财管
我想要在同一列表中看到核算状态与累计核算金额的真实值
以便于判断某笔预付费的分摊是否已进入 OBS 核算。

## 需求点

1. 在资源运营「云账单管理」下提供独立「预付费管理」入口与独立列表页，不挂固定账单月份选择器。
2. 页面只读：无新增、无编辑、无删除、无导出、无失败重试。
3. 入口权限对齐云账单形态、权限点用二级账号查看（`main_account_find`）：无权限时隐藏「预付费管理」菜单；直链不走守卫申请页，由列表接口自行鉴权。
4. 默认展示基础筛选：使用时间、运营产品、二级账号名称。
5. 高级筛选可折叠展开：一级账号名称、GPU 型号、产品名称、云厂商、订单月份起止区间；不提供「订单时间」范围筛选项。
6. 使用时间选择到日期；开始日不得晚于结束日；查询时按开始日 00:00:00、结束日 23:59:59 生效。
7. 订单月份为起止月份闭区间，开始月不得晚于结束月。
8. 账号筛选界面按名称选择，查询按账号身份生效（不按名称字符串匹配）。
9. 筛选全空时查权限范围内全部数据（仍分页）；多条件同时生效（全部满足）。
10. 列表固定 22 列只读展示；列多时横向滚动。列依次为：预付费 ID、订单月份、资源 ID、运营产品、二级账号名称、一级账号名称、GPU 型号、数量(台)、数量(卡)、优惠后总价(不含税)、累计核算金额、核算状态、币种、产品名称、产品规格、Region、使用开始时间、使用结束时间、订单时间、发票 ID、云厂商、单据状态。
11. 预付费 ID 可点进详情页入口；本期不交付详情内容，未交付时允许空页，不在本页展开详情。
12. 核算状态（待核算 / 核算中 / 已完成）与累计核算金额始终展示真实值，不因未定账 / 失败显示为空占位。
13. 失败原因不出现在列表。
14. 默认按订单时间从新到旧；分页沿用现网列表默认页大小，单页不超过 500。
15. 产品财管与二级账号负责人只看被授权二级账号；管理员看全部。
16. 非管理员且无任何二级账号授权时展示空态，不是权限申请整页，也不是全量数据。
17. 筛选非法时提示错误并保留当前筛选，不清空成全量；查询失败时提示并可重试，不覆盖为错误全量。
18. 金额不做脱敏。

## 单据状态取值

未定账 / 已定账 / 失败。

## 本期不包含

- 导出全部
- 详情页主信息与分摊整合表
- 账单调整列表的推送状态 / 定账状态 / 操作守卫
- 新增 / 编辑 / 删除 / 失败重试
- 改造现网「云账单管理」固定月份模型
- 后端列表接口实现（弱依赖 `1069995598137352704`，无接口可用 mock 并行，联调必须对齐）

## 验收标准

- AC-001：独立列表页，无固定月份选择器，无新增、无导出。
- AC-002：默认筛选项与高级筛选项齐全；使用时间只到日期；无「订单时间」范围筛选项。
- AC-003：开始日晚于结束日 → 提示不合法且不发出有效请求。
- AC-004：同日查询时按当日 00:00:00 ~ 23:59:59 生效。
- AC-005：订单月份 2026-07 ~ 2026-09 为闭区间（含 07 与 09）。
- AC-006：账号选择器选名称，查询按账号身份生效。
- AC-007：1–22 列完整且只读。
- AC-008：点预付费 ID 进详情入口；本期允许空页。
- AC-009 / AC-010：未定账或失败时核算字段仍展示真实值，不是空占位；失败原因不在列表出现。
- AC-011 / AC-012 / AC-013：行级隔离、空授权空态、管理员全量可分页。
- AC-014：多条件全部满足才命中。
- AC-015：默认订单时间从新到旧。
- AC-P01：单页不超过 500，默认页大小与现网一致。
- AC-S01 / AC-S02：无 `main_account_find` 藏菜单（对齐云账单 `checkAuth`，直链不 403）；筛选不能越权。

## 待确认

- Q-001：核算字段如实展示是否长期保留，待财务试用后确认。本期按不遮蔽验收；若体验不佳再改回「仅已定账展示」。
- 订单月份区间：若列表查询目前只收单月，需后端配合改为起止月份（联调对齐点）。
