# Design：aiagent-同会话内动态切换场景标签（无设计稿）

> **本迭代无独立设计稿**。豁免原因：沿用现网全屏 chatbot 的场景 chip 与左侧场景文件夹 UI；本期仅为收到后端场景切换指令后同步更新既有标签展示，无新视觉稿、无新组件形态。浮窗无外显标签（PRD F-004）。

## 0. 本子需求范围

| 在本迭代内 | 不在本迭代内 |
|------------|--------------|
| 全屏：现有只读场景 chip 文案随会话标签更新 | 新设计场景标签样式 / 新 chip 形态 |
| 全屏：现有侧栏场景文件夹因标签变更而重新归组展示 | 浮窗新增外显场景标签 |
| 浮窗：仅数据侧标签更新（无 UI 增量） | history 回放驱动的标签切换 UI |
| 切换过程不打断流式气泡展示 | 场景映射表运营配置界面 |

## 2. UI 参照

- **现网全屏 chatbot**：`views/chatbot/index.vue`
  - **聊天区场景标签**：输入区 `#input-header` 内 `.scene-chip`（只读时无关闭按钮；文案来自 `resolveSessionTagName(sessionTag)`）
  - **左侧会话列表**：历史对话区按 `sessionTag` 分文件夹；文件夹名 `resolveSessionTagName(folder.tag)`；展开图标沿用现有 `bkhcm-icon-folder-open` / `bkhcm-icon-folder-close`
- **现网浮窗**：`components/ai-assistant`（与全屏共用会话内核）；**无**场景 chip / 侧栏文件夹外显
- **PRD 文字约束**：
  - 切换后全屏 chip 与侧栏文件夹必须与同一会话场景标签一致（AC-001）
  - 未知场景标识展示原始值（AC-003）
  - 浮窗不新增外显标签（AC-004）
  - 流式展示不被中断（AC-007）

## 3. 交互与状态（沿用现网）

| 场景 | 期望表现 |
|------|----------|
| 当前会话收到切换指令 | 只读 chip 文案立即变为新场景展示名；该会话从旧文件夹移入新文件夹（若新文件夹折叠，沿用现有展开态规则，不强制弹开） |
| 多次切换 | 以最后一次为准，chip 与文件夹同步 |
| 未知场景标识 | chip / 文件夹名显示原始标识字符串 |
| 非当前会话（本地列表有该项） | 仅列表归组更新；不强制切到该会话；当前会话 chip 不变 |
| 浮窗收到指令 | 无标签 UI 变化；进入全屏后可见正确 chip/文件夹 |
| 流式进行中切换 | 文本/卡片继续流式；标签并行更新 |

## 3.y 组件复用（通识）

| 界面块 | 复用层级 | 说明 |
|--------|----------|------|
| 场景 chip | 页面内既有 DOM（`.scene-chip`） | 不新建组件；数据源变为「可随场景切换更新的会话标签」 |
| 侧栏文件夹 | 页面内既有列表派生（`sidebarSessions.folders`） | 标签变更后自然重算归组 |
| 浮窗 | 共用会话内核 | 无标签 UI 增量 |

## 4. 与 PRD 验收映射

| PRD 验收项 | Design 结论 |
|------------|-------------|
| AC-001 chip + 文件夹切换 | 沿用现网 chip / 文件夹形态，仅数据驱动更新 |
| AC-002 多次切换取最后一次 | 无额外 UI；状态以最新标签为准 |
| AC-003 未知 to 展示原值 | 沿用现网 `resolveSessionTagName` 回退行为 |
| AC-004 浮窗无外显标签 | 设计上明确无浮窗标签增量 |
| AC-005 刷新后标签 | 无 UI 增量；依赖服务端返回（联调） |
| AC-006 缺 to 忽略 | 无 UI 变化 |
| AC-007 不打断流式 | 无遮罩/无阻断交互；标签就地更新 |
