## 验证范围

- 功能边界: 当前会话 SSE 流式中收到 `CUSTOM` / `scene.switched` 后，同步更新本地会话 `sessionTag`；全屏聊天区只读 chip 与左侧场景文件夹随之变化；浮窗仅数据更新、无外显标签
- 不在范围: history 回放处理、浮窗新增外显标签、后端 `session_tag` 持久化实现本身（仅联调验证是否已落库）、场景映射运营配置

## 测试环境

- 前端入口: 全屏 chatbot 路由页 + 业务页浮窗助手（由执行人确认测试环境）
- 测试账号: `<test_account>`
- 数据准备:
  - 后端 Agent 能在对话中下发 `scene.switched`（例：`from=host_apply` → `to=resource_query`）
  - 或开发者工具 / mock 向当前会话 SSE 注入等价 CUSTOM 事件
  - 准备至少一个已打 `host_apply` 标签的会话，便于观察文件夹迁移

## 用例清单

### P0 - 主流程（必测）

| ID | 场景 | 前置 | 操作 | 期望 | 回滚 |
|----|------|------|------|------|------|
| P0-01 | 全屏 chip + 文件夹切换 | 全屏打开 `host_apply` 会话，chip 为「主机申领」，会话在「主机申领」文件夹 | 对话流式中触发 `scene.switched` 且 `to=resource_query` | chip 变为「资源查询」；会话出现在「资源查询」文件夹并离开「主机申领」；流式文本/卡片不被中断 | 无；可再切回或结束会话 |
| P0-02 | 多次切换取最后一次 | 同 P0-01 会话流式中 | 连续下发 `to=resource_query` 再 `to=host_apply`（或反向） | chip 与侧栏均以最后一次 `to` 为准 | 无 |
| P0-03 | 浮窗数据侧 | 浮窗打开同会话并流式对话 | 触发 `scene.switched` | 浮窗无新增外显标签；进入全屏后 chip/文件夹为新场景 | 无 |
