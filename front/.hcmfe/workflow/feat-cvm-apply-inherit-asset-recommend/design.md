### 2.2 下拉选择器结构

- **外壳**：`bk-select` + `custom-content` + `allow-create` + `clearable`
- **trigger**：`bk-input`（behavior="simplicity"），支持手动输入固资号
- **下拉面板**：`AssetList` 组件（`v-if="isDropdownOpen"` 懒渲染）
- **popover-min-width**：900px
- **scroll-height**：500px

### 2.3 下拉面板内部结构

- **顶部**：机型族 Tab（`bk-tab` type="unborder-card"）
  - 每个 Tab 标注候选数量（`num-display-type="elliptic"`）
  - 候选数为 0 的 Tab **直接隐藏**
  - Tab 无设备时展示文案「该机型族没有符合要求的CVM实例」
- **内容区**：`bk-table` 候选固资列表
  - 列：固资号（含推荐圆点）/ IP / 机型 / 计费模式（剩余时长）/ 开始时间 / 结束时间
  - 推荐项（已使用时长 ≥ 36 个月）置顶，橙色圆点 badge 标记
  - 其余按已使用时间降序排列

## 3. 关键交互

### 3.1 下拉展开/收起

- 点击 trigger 输入框展开下拉面板
- `@toggle` 事件控制 `isDropdownOpen`，面板内容 `v-if` 懒渲染
- 面板根元素 `@click.stop` 防止 clickoutside 关闭（bk-select customContent 已知陷阱）

### 3.2 机型族 Tab 切换

- 切换 Tab 时重新触发推荐逻辑
- 覆盖之前选择
- 候选数为 0 的 Tab 直接隐藏（不展示）
- Tab 无设备时展示文案

### 3.3 选择固资

- 点击表格行选中固资号
- 选中后：
  1. 填入 trigger 输入框
  2. **自动调用「手动校验」**（调用 `cvmDeviceStore.getInheritCvm`）
  3. 校验通过 → 锁定计费模式 + 购买时长 + 展示「已继承固资套餐」
  4. 校验失败 → 提示具体原因

### 3.4 手动输入

- 在 trigger 输入框中直接输入固资号
- 点击「手动校验」按钮执行校验
- 不改变当前逻辑（沿用 `handleCheck`）

### 3.5 可用区联动

- 可用区选中（含默认）→ 立即触发推荐
- 切换可用区 → 重新推荐，覆盖之前选择
- **可用区选到「全部」→ 取消固资号回填**（可用区选择器有"全部"选项）

### 3.6 自动回填策略

- 后端返回大列表 → 前端分组（按机型族 Tab）
- 排序前端确定
- 回填规则：**有标准型优先标准型，没有标准型取第一个数据回填**
- 回填后自动调用「手动校验」

## 4. 状态流转

### 4.1 固资号选择器状态

```
[空态] ──可用区选中──> [推荐中] ──推荐完成──> [已回填+自动校验中]
                                              │
                                    ┌─────────┴─────────┐
                                    │                   │
                              [校验成功]            [校验失败]
                                    │                   │
                              [已继承固资套餐]      [提示原因]
                                    │
                              [锁定计费+时长]
```

### 4.2 手动输入状态

```
[空态] ──用户输入固资号──> [已输入] ──点击手动校验──> [校验中]
                                                        │
                                              ┌─────────┴─────────┐
                                              │                   │
                                        [校验成功]          [校验失败]
                                              │                   │
                                        [已继承固资套餐]    [提示原因]
```

### 4.3 Tab 切换状态

```
[当前 Tab 展示候选列表] ──切换 Tab──> [重新推荐] ──推荐完成──> [覆盖之前选择 + 自动校验]
```

### 4.4 可用区联动状态

```
[当前固资号已选] ──切换可用区──> [重新推荐] ──推荐完成──> [覆盖之前选择 + 自动校验]
[当前固资号已选] ──可用区选到「全部」──> [取消回填] ──> [清空固资号 + 解锁]
```

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 候选固资列表为空 | Tab 不展示（候选数为 0 的 Tab 直接隐藏） |
