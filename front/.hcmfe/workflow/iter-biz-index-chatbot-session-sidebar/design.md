# Design：业务视角首页 chatbot - 侧边栏会话列表

> 编写前已通过 Figma MCP（`2008-8150`、`2031-1317`）及用户提供的交互说明图识别稿面。冲突以 **稿面 + 用户确认** 为准。

## 0. 本子需求范围（Design 阶段约束）

**仅交付：会话侧栏列表的分组结构、交互与视觉对齐。**

| 在本子需求内 | 不在本子需求内 |
|--------------|----------------|
| 侧栏顶部 **搜索对话**（前端过滤会话列表） | 路由、顶栏、业务左侧菜单（上一迭代已完成） |
| 侧栏顶部「新对话」入口样式对齐稿面 | 主对话区消息/HITL/流式交互改造 |
| 会话列表分组（置顶 / 历史对话 / 标签文件夹） | 删除确认、置顶持久化等**交互逻辑变更**（沿用现实现） |
| 列表项默认 / hover / 选中态、文件夹展开收起 | **拖拽排序 / 跨组拖放**（下一迭代） |
| 会话管理菜单（置顶、重命名、删除） | 归档、批量删除等未在现网存在的管理能力 |
| 侧栏展开态与收起态（窄条 + hover 浮层） | |
| 空态、滚动区域 | |

对齐 PRD：`prd.md` 第 3～6 节。

## 2. 信息架构 / 布局

自上而下四块（与稿面一致）：

```
┌─ 会话侧栏（256px）─────────────────┐
│  [ 搜索对话 ]          ← 本迭代实现（前端过滤） │
│  [ 新对话 ]            ← 渐变主按钮           │
│                                              │
│  置顶                    ← 大组标题（12px 弱色）│
│  ├─ 会话项（右侧置顶图标）                    │
│  └─ ...                                      │
│                                              │
│  历史对话                ← 大组标题           │
│  ├─ 未分组会话（平铺，无文件夹）              │
│  ├─ 📁 主机申领  [2]     ← 展开：实心文件夹   │
│  │    ├─ 会话…         ← 左缩进 + 虚线引导   │
│  │    └─ 会话…                               │
│  ├─ 📁 预测提单  [3]     ← 收起：空心文件夹   │
│  └─ 📁 主机回收  [1]                         │
│                                              │
│  [ 收起侧栏 ]                                │
└──────────────────────────────────────────────┘
```

### 2.1 大组：置顶

- 标题文案：**「置顶」**（12px，`#979BA5` 弱色，左内边距 8px）
- 置顶会话**平铺**，每项高度 **32px**，圆角 4px
- **默认态**：白底；会话名左侧有小圆点/会话图标；**右侧常驻置顶图标**（非 hover 也可见）
- **无置顶会话时**：整组**不展示**（不占空标题）

### 2.2 大组：历史对话

- 标题文案：**「历史对话」**（见 §6 与 PRD「历史会话」差异）
- 包含所有**未置顶**会话
- 组内自上而下：
  1. **未分组区域**：无标签（场景模板）的会话，**无文件夹包裹**，直接平铺
  2. **标签文件夹**：有标签的会话归入对应文件夹；文件夹名为标签名
- **组内排序**（未分组与各文件夹内）：**最近活跃在前**（`updated_at` 降序）
- **多文件夹排序**：按该文件夹内 **max(updated_at) 降序**（最近有活动的文件夹靠前）

### 2.3 标签文件夹（分组行）

| 元素 | 说明 |
|------|------|
| 文件夹图标 | **展开**：实心文件夹；**收起**：空心文件夹 |
| 文件夹名 | 12px 正文色，即会话标签名 |
| 数量角标 | 灰色圆角 Tag（10px 字），展示组内会话数，如 `2` |
| 子会话 | 相对分组行 **左缩进 24px**；展开时左侧有 **竖向虚线** 连接父子 |
| 空文件夹 | **自动隐藏**（交互说明：用户不可手动增删分组） |

> 分组来源：新建会话时按**场景模板**自动归入对应标签组（与 PRD「会话标签」一致）；用户不能手动新建/删除分组。

## 3. 关键交互

### 3.1 搜索对话

- 位置：侧栏**最上方**（新对话按钮之上），与稿面 `2008-8150` 一致
- 样式：高 32px，圆角 4px，背景 `#F0F1F5`；占位文案 **「搜索对话」**（12px `#979BA5`）；右侧搜索图标 16px
- 行为：**前端本地过滤**当前已加载的会话列表（匹配会话名称，大小写不敏感）；不发起新接口
- 过滤范围：同时作用于 **置顶** 与 **历史对话**（含文件夹内子项）；无匹配项时列表区展示 **「无匹配会话」** 类空态，大组标题可保留或按实现隐藏空组
- 清空关键词后恢复完整列表；侧栏收起 hover 浮层内搜索行为与展开态一致
- 收起窄条（`2031-1317`）**不展示**搜索框（仅展开 / 浮层完整态可用）

### 3.2 新对话入口

- 全宽主按钮：**渐变蓝底**（`#0061A5` → `#0D99FF`），白字 **「新对话」**，左侧对话图标，高度 36px，圆角 4px，带轻阴影
- 点击行为与现网「开启新对话」一致（创建会话并清空输入）
- 文案以稿面 **「新对话」** 为准（替换现网「开启新对话」）

### 3.3 会话条目

| 状态 | 视觉 / 行为 |
|------|-------------|
| **默认** | 白底 `#FFFFFF`；单行会话名 12px `#313238` |
| **Hover** | 背景 `#F0F1F5`；**右侧操作区由置顶图标切换为「更多」三点图标**（历史区默认无右侧图标，hover 才出现更多） |
| **更多图标 Hover** | 图标外圈灰色圆形底 |
| **选中 / 当前会话** | 与 hover 相同浅灰底 `#F0F1F5`（稿面示例：`GPU库存情况`） |
| **会话名** | 超长截断与 tooltip **沿用现网** `OverflowTitle` |

### 3.4 更多菜单

点击「更多」展开下拉（置顶区与历史区菜单项不同）：

| 区域 | 菜单项（自上而下） |
|------|-------------------|
| **置顶区** | 取消置顶 → 重命名 → 删除 |
| **历史区** | 置顶 → 重命名 → 删除 |

- **重命名**：行内输入框；**Enter** 或 **失焦** 保存（与现网一致）
- **删除**：二次确认弹窗（标题「删除此会话？」、危险确认按钮）；确认后删除并处理当前会话回退（沿用现网）
- **置顶 / 取消置顶**：置顶后移入「置顶」组；取消后回到历史对应对应位置（未分组或文件夹内）

### 3.5 文件夹展开 / 收起

- 点击文件夹行切换展开 / 收起
- 展开：实心文件夹 + 展示子会话 + 左侧虚线引导
- 收起：空心文件夹 + 隐藏子会话
- 默认展开态：实现时可默认**全部展开**，或记住用户折叠状态（无稿面强制要求时，优先**全部展开**以降低复杂度）

### 3.6 切换会话

- 点击条目（非更多按钮）→ 主对话区切换；URL 同步 `/business/chatbot/:sessionCode`
- 选中态即时更新

### 3.7 侧栏收起 / 展开

| 态 | 表现 |
|----|------|
| **展开**（`2008-8150`） | 完整侧栏：搜索行右侧 **收起按钮（左指向 chevron）** + 新对话 + 列表，可滚动；**无**底部收起按钮 |
| **收起**（`2031-1317`） | 左侧 **竖向胶囊浮条**（白底、大圆角 pill、轻阴影向右浮出；**非**通栏占满高度）：上 **右指向 chevron**（展开），下 **对话气泡+加号**（新对话） |
| **收起 + Hover 触发区** | 沿用现网：左侧 8px 触发条 hover 时 **浮层展示完整侧栏**（`2008-8150` 结构），分组规则与展开态一致 |

> 收起控件位置（用户确认稿）：展开态收起按钮为 **圆形浮起按钮，悬浮贴在侧栏右边缘、跨过分割线**（与搜索行垂直对齐，白底 + 细边 + 轻阴影），不占用搜索框宽度。展开/收起 chevron 统一使用 bkui `AngleDownLine` + CSS 旋转：收起按钮旋转 `90deg`（左指 `<`），收起胶囊展开按钮旋转 `-90deg`（右指 `>`）。
> 收起态操作按钮（展开 `>` + 新对话）：左上角竖向胶囊，**顶部对齐**（非垂直居中）。
> 会话条目：标题前有 **小圆点**（`#C4C6CC`，4px）；**置顶图标与更多三点图标占同一最右槽位**（置顶常驻、hover 切换为更多）。

### 3.7.1 关键图标语义（`2031-1317` / `2008-8150`）

| 稿面位置 | 语义描述 | Node |
|----------|----------|------|
| 展开态-收起按钮 | 搜索框右侧，左指向 chevron，点击收起侧栏（bkui `AngleDownLine` 旋转 90°） | 用户确认稿 |

## 4. 状态流转（列表相关）

### 4.1 置顶

```
历史对话中的条目 → 菜单「置顶」→ 移入「置顶」组（组内按 updated_at 排序）
置顶条目 → 菜单「取消置顶」→ 回到「历史对话」对应文件夹或未分组位置
```

### 4.2 删除

```
菜单「删除」→ 确认弹窗 → 确认 → 列表移除
若删当前会话 → 自动切至相邻可用会话或空态新对话
若删置顶会话 → 同步清除本地置顶记录
```

### 4.3 重命名

```
菜单「重命名」→ 行内编辑 → Enter / 失焦确认 → 名称更新（分组位置不变）
```

### 4.4 新建会话

```
点击「新对话」→ 创建会话 → 按场景模板自动归入对应标签文件夹（若无标签则落在未分组区域）
```

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 无任何会话 | 列表区空态；「新对话」仍可用 |
| 仅有置顶或仅有历史 | 只展示对应大组 |
| 历史无未分组、仅有文件夹 | 「历史对话」下直接展示文件夹 |
| 文件夹内会话数为 0 | 文件夹不展示 |
| 侧栏收起再展开 / hover 浮层 | 分组、选中态、文件夹展开状态与展开态一致 |
| 列表过长 | 侧栏列表区域可滚动 |
| 搜索无匹配 | 列表区提示无匹配会话；清空搜索恢复 |
