## 1. 需求背景

上一子迭代（`iter-biz-index-chatbot-route-layout`）已完成业务视角 chatbot 的路由与页面布局。本子需求聚焦**会话侧边栏列表**：在既有交互能力基础上，统一列表分组与排序规则，并保证与主对话区、URL 联动一致。

## 2. 用户故事

- 作为使用 AI 助手的用户，我希望在侧边栏按「置顶 / 历史会话」快速定位会话，并一键切换。
- 作为需要整理会话的用户，我希望置顶、重命名、删除等管理能力在侧栏内可直接完成。
- 作为有标签会话的用户，我希望历史对话按标签分组浏览，未打标签的会话优先展示在上方。
- 作为会话较多的用户，我希望通过搜索快速过滤侧边栏中的会话名称。

## 3. 功能范围

### 3.1 侧边栏会话列表 UI（本迭代必须）

| 项 | 要求 |
|----|------|
| **搜索对话** | 侧栏顶部提供搜索框（占位「搜索对话」）；**前端本地**按会话名称过滤列表（大小写不敏感）；无匹配时明确空态；清空后恢复完整列表；侧栏收起窄条态不展示搜索（展开 / hover 浮层可用） |
| **列表展示** | 展示会话条目（至少会话名称），当前会话有明确激活态 |
| **列表交互** | 点击切换会话；主对话区与 URL（`/business/chatbot/:sessionCode`）同步 |
| **展开/收起适配** | 会话侧栏展开/收起两种状态下列表可用 |
| **空态** | 无会话时提供明确空态反馈 |

### 3.2 列表分组与排序（本迭代必须）

侧边栏分为 **两个大组**（自上而下）：

| 大组 | 展示规则 |
|------|----------|
| **置顶** | 所有置顶会话**平铺**展示，不再按日期或标签二次分组 |
| **历史对话** | 非置顶会话归入此组；组内规则见下 |

**历史对话**组内结构（自上而下）：

1. **未分组会话**：无会话标签的条目，平铺在组内**最上方**
2. **标签分组**：其余会话按**会话标签**分组展示；每组有分组标题（标签名）
3. **组内排序**：同一标签分组内（以及未分组区域），按**最近活跃在前**排序（以会话 `updated_at` 为准）

> 说明：本迭代将替换现网「置顶 + 按日期（今天/昨天/7 天内…）」的历史分组方式，改为上述「置顶 + 历史对话（标签分组）」结构。

### 3.3 会话管理能力（沿用现实现，本迭代验收）

以下能力**已在现网实现**，本子需求**保持行为不变**，仅随新分组结构正确挂载展示：

| 能力 | 要求 |
|------|------|
| **置顶 / 取消置顶** | 侧栏菜单可操作；置顶数据按用户本地持久化 |
| **重命名** | 行内编辑确认后更新列表名称 |
| **删除** | 操作前弹出**二次确认**（标题/文案/危险按钮与现网一致）；确认后删除并处理当前会话回退 |
| **反馈** | 操作成功/失败有可感知反馈 |

### 3.4 会话名称展示（沿用现实现）

- 会话名称截断、省略与 hover 展示规则**保持现网实现**（不重定义长度与 tooltip 策略）。

### 3.5 权限与入口约束（沿用）

- 入口与访问统一改用**业务视角 chatbot 权限** `biz_agent_assistant`（`store/common.ts`，`agent_assistant`/`find`，按 `bk_biz_id` 鉴权）控制「首页」入口与 `/business/chatbot` 访问；无该权限则不展示入口。
- 默认首页兼容：有 `biz_agent_assistant` 时 `/`、`/business`、`/business/host` 默认进 chatbot；无权限回退到主机页（资源管理默认页），系统其它顶栏默认页行为不受影响。
- 冷启动业务未选中时，路由守卫先从 URL / localStorage 解析 `bizs` 注入鉴权，老用户可落到 chatbot，新用户（无 biz）安全回退主机页。
- 无权限用户不进入 chatbot 页，不涉及侧栏列表。

## 4. 非目标（不在本迭代范围）

- 新增 Agent 后端协议或会话 CRUD 接口形态变更（标签字段若后端未返回，在 API 阶段对齐数据来源，不在 PRD 展开技术方案）
- 会话跨业务隔离（`/bizs/{bizId}/`）
- 消息区、HITL、流式对话交互改造
- 顶层路由与全局布局调整
- 归档、批量删除等未在现网存在的管理能力
- **拖拽排序 / 跨组拖放**（设计稿交互说明有，下一迭代再做）

## 5. 验收标准

### P0

- [ ] 侧栏顶部 **搜索对话** 可按名称过滤列表；无匹配有空态；清空恢复。
- [ ] 侧栏展示 **「置顶」**、**「历史对话」** 两个大组；置顶会话仅在置顶组内平铺。
- [ ] 历史对话中：**未打标签**会话在组内最上方；**有标签**会话按标签分组展示。
- [ ] 未分组区域与各标签组内，会话按**最近活跃在前**排序。
- [ ] 点击会话可切换，当前会话高亮，URL 与主对话区同步。
- [ ] **置顶 / 取消置顶、重命名、删除（含二次确认）** 行为与改前一致且在新分组下可用。
- [ ] 删除当前会话后，列表与当前会话回退正确。

### P1

- [ ] 侧栏收起再展开后，分组、当前会话状态一致。
- [ ] 仅置顶或仅历史、空列表等边界场景无报错、无白屏。
- [ ] 会话名称截断与 hover 表现与现网一致。
