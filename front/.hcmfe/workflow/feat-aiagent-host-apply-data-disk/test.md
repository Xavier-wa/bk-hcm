## 验证范围

- 功能边界：chatbot 主机申领**预提单卡（B 卡）**的「调整配置」弹窗，数据盘表单项的增删行能力、总块数上限、行内字段校验，以及随之调整的弹窗宽度与下拉选项请求行为。
- 不在范围：
  - 推荐方案默认值（woa-server 仍无条件带 1 块 500G 数据盘，本次不改）
  - 推荐方案卡（A 卡）的「调整配置」入口（仍为注释态）
  - 系统盘的增删能力（系统盘必填）
  - 后端提单接口与 agent skill（均未改动）
  - 非 chatbot 的主机申领表单页面
  - 三级账号创建侧滑的同类下拉重复请求问题（已确认另起单据）

## 用例清单

### P0 - 主流程（必测）

| ID | 场景 | 前置 | 操作 | 期望 | 回滚 |
|----|------|------|------|------|------|
| P0-01 | 删除数据盘至零块并保存 | B 卡已出现，某行数据盘为默认 1 块 | 点该行「调整配置」→ 数据盘行尾点减号 → 点「保存修改」 | 弹窗关闭无报错；**不出现**「请完善必填项」；预提单表格该行数据盘列为 `--` | 重新打开弹窗点加号恢复 |
| P0-02 | 零块空态添加一行 | 已按 P0-01 删至零块，弹窗仍打开 | 数据盘区域点大加号按钮 | 新增一行，默认值为**高性能云盘 / 500 / 1 块** | 点减号删除 |
| P0-03 | 已有行追加一行 | 数据盘已有 1 行且容量已改为 600 | 点该行行尾加号 | 末尾追加一行（高性能云盘 / 500 / 1）；**已有行的 600 不受影响** | 删除新增行 |
| P0-04 | 删空保存后重开弹窗 | 已按 P0-01 删空并保存 | 再次点同一行「调整配置」 | 数据盘仍为**零块**，只显示大加号空态按钮，未被推荐默认值填回 | 无 |
| P0-05 | 零块配置提交载荷正确 | 已按 P0-01 删空并保存，Network 面板已打开 | 点「确认方案」→ 查看 `/api/v1/agent/agui` 请求体 | `resumeValue` 内该子单为 `"data_disk":[]`（键保留、值为空数组，不是缺键也不是 `null`）；agent 后续不再补默认盘 | 无（会推进会话，建议放在其他用例之后执行） |
| P0-06 | 多条数据盘提交载荷正确 | 数据盘配成 3 行且容量各不相同，已保存 | 点「确认方案」→ 查看请求体 | `data_disk` 为含 3 个对象的数组，**顺序与弹窗行序一致**；`disk_size` / `disk_num` 为数字而非字符串 | 无 |

### P1 - 异常分支（必测）

| ID | 场景 | 前置 | 操作 | 期望 |
|----|------|------|------|------|
| P1-01 | 总块数达上限禁用添加 | 弹窗打开 | 把某行数量调到 20（或多行数量之和为 20）→ hover 行尾加号 | 加号置灰（图标色变浅）；hover 提示「数据盘总块数最多 20 块」；点击无反应、不新增行 |
| P1-02 | 数量输入框收敛上限 | 已有 1 行数量为 18 | 尝试把该行数量调到 25 | 无法超过剩余额度（该行上限 = 20 − 其他行已占用块数），总块数不会突破 20 |
| P1-03 | 清空容量后保存被拦 | 数据盘至少 1 行 | 清空该行容量输入框 → 点「保存修改」 | 表单红字提示「数据盘信息不能为空」；**弹窗不关闭、不回写卡片**；不产生提交请求 |
| P1-04 | 清空数量后保存被拦 | 数据盘至少 1 行 | 清空该行数量输入框 → 点「保存修改」 | 同 P1-03，被同一条校验拦住 |
| P1-05 | 改容量/数量不触发下拉请求 | 弹窗打开，Network 面板已打开并清空记录 | 在容量、数量输入框连续输入若干字符；再拖动浏览器窗口改变可视区域大小 | Network **不出现**磁盘类型、地域、机型、操作系统、需求类型等任何下拉选项接口的新请求（这是本次修复的核心回归点） |
| P1-06 | 地域变更仍级联重拉（回归） | 弹窗打开，Network 面板已打开 | 切换「地域」为另一个地域 | 机型与操作系统的选项接口**各重新请求一次**，且两者选中值被清空——确认固化选项工厂引用后响应性未被打断 |
| P1-07 | 跨标签切换不覆盖本地草稿 | 已在弹窗删空数据盘并「保存修改」，但**未**点「确认方案」 | 切到浏览器其它标签页停留数秒再切回 | 预提单表格该行数据盘仍为 `--`，未被服务端原始值（1 块 500G）覆盖 |

### P2 - UI 细节（按需）

- [ ] 弹窗加宽后（800px），数据盘行的容量输入框**数值完整可见**，不再被步进器与 `GB` 后缀挤掉
- [ ] 数据盘行的三个控件 + 加减号按钮在一行内排布正常，无换行、无横向滚动
- [ ] 「数据盘」标签右侧有说明图标，hover 提示「数据盘大小范围为20G-32000G，且为10的倍数」
- [ ] 容量输入框步进器**以 10 为步长**增减
- [ ] 磁盘类型选为「SSD 云硬盘」时，容量下限为 20；选为「高性能云盘」时下限为 10
- [ ] 加号按钮禁用态图标色比可用态更浅（`#eaebf0` vs `#c4c6cc`）
- [ ] 零块时只显示一个大加号按钮（无空行、无残留的行内加减号）
- [ ] 某子单数据盘为空时，预提单表格与确认提交卡的数据盘处展示为 `--` 或不展示该行，页面不报错、不白屏
- [ ] 在预提单卡「全屏」态下打开「调整配置」弹窗，弹窗不被全屏遮罩盖住（z-index 抬高生效）
