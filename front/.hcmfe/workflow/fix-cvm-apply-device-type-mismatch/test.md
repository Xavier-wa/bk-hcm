# Test — fix-cvm-apply-device-type-mismatch

## 测试范围

修复 `device-type-dialog.vue` 两处缺陷：
- **改动 A**：`handleZoneSelect` / `handleDeviceGroupChange` 末尾清空 `condition.deviceType/cpu/mem`
- **改动 B**：`bk-option` 的 `:key` 从 `index` 改为 `item.device_type`

## 数据准备

- 进入「主机申领」页面，打开 CVM 申领弹窗
- 确保可用区列表包含「全部」+ 至少 2 个具体可用区（如南京一区、南京二区）
- 确保机型列表在不同可用区下有差异（至少有 1 个机型只在某可用区下存在）

## 风险点

- **改动 B 的副作用**：`:key` 改为 `item.device_type` 后，如果 `option.deviceTypeList` 中存在重复的 `device_type`，Vue 会报 key 重复警告。需确认接口不会返回重复机型。
- **bk-select 内部状态**：改动 B 依赖 bk-option 的 unmount/remount 触发 register/unregister，若 bkui-vue 版本升级改变了该生命周期行为，需重新评估。
