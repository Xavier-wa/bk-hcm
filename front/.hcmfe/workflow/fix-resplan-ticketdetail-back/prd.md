## 背景与目标

调整预测提交后进入申请单详情，页内返回箭头无响应。从单据列表进入同一详情则能返回。本期修提交路径，不把详情迁到新面包屑。

## 用户故事

1. 作为 **提单人**，我想在调整提交进入详情后点返回回到单据列表，以便继续处理其他单据。
2. 作为 **提单人**，我想从列表进入详情后仍能回到列表，以免原路径被改坏。

## 功能需求点

### F-001 提交后详情返回单据列表（P0）

- 维持页内详情头，不迁全局面包屑。
- 详情已配置的「返回单据列表」（资源预测 tab + 当前业务）必须真正作为跳转目的地。
- 没有从列表带入的返回上下文时，不得空点无响应。

### F-002 列表进入详情的返回保持（P0）

- 从单据列表打开同一张详情，返回仍回列表（含现网 tab / 筛选上下文）。

## 业务规则

| 编号 | 规则 |
| --- | --- |
| R-001 | 不迁新面包屑，只修旧详情头返回失效。 |
| R-002 | 提交后返回单据列表，不去调整页或预测资源列表。 |
| R-003 | 列表进入详情的返回必须保持。 |
| R-004 | 「返回单据列表」配置在没有列表上下文时也是目的地，不能只当补参。 |

## 验收标准

- **AC-001** Given 调整提交成功进入详情 When 点页内返回 Then 进入单据列表（资源预测、当前业务）
- **AC-002** Given 从单据列表打开详情 When 点页内返回 Then 仍回单据列表
- **AC-003** Given 工作台视角同类详情 When 点返回 Then 回工作台单据列表

## 边界

### 包含

- 资源预测申请单详情页内返回箭头

### 不包含

- 迁新面包屑 / `_f` 作为产品模式
- 返回调整页或预测列表
- 普通申请单详情、浏览器后退键

## 接口与设计

- 无新接口、无新视觉。复用现有页内详情头与「返回单据列表」配置。
