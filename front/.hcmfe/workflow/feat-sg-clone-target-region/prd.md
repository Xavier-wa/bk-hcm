# PRD：安全组-克隆支持选择目标地域

> TAPD 单据：story 1069995598136749088（短 ID 136749088）
> 需求澄清稿：`docs/reqs/安全组克隆地域.md`（第 1 轮 7 问已全部回复）
> 全量解读来源：tapd-analyst 结构化摘要（2026-08-28）

## 需求背景

BK-HCM 平台上，用户可对安全组执行「克隆」操作以快速复制一套配置。当前克隆逻辑**仅能克隆到与源安全组相同的地域**，页面不支持选择其他地域，无法满足跨地域快速复制安全组的需求（例如将广州地域的安全组模板复制到南京地域）。

后端克隆接口已支持 `target_region` 参数，本需求聚焦于**前端交互补齐**：在克隆弹窗中提供「目标地域」选择。

## 用户故事

* 作为**业务运维用户**，我想要在克隆安全组时选择目标地域，以便于将一套安全组配置快速复制到不同地域，减少重复配置。
* 作为**业务运维用户**，我希望克隆弹窗的负责人/备份负责人默认带出源安全组的值并可修改，以便跨地域克隆时快速完成表单。

## 功能需求（净需求点清单）

| 编号 | 需求描述 | 优先级 |
| --- | --- | --- |
| F-001 | 安全组克隆弹窗新增「目标地域」下拉：选项为当前业务（bk_biz_id）可用地域全集（复用现有地域字典/枚举）；**默认值 = 源安全组所在地域**（保持原同地域克隆行为，向后兼容）；用户可改为其他地域提交 | P0 |
| F-002 | 弹窗「负责人」「备份负责人」默认回填源安全组对应值，用户可修改；提交时将（可能被覆盖后的）manager/bak_manager 一并提交 | P1 |
| F-003 | 结果反馈：成功 → 提示「已克隆至 {目标地域}」，**停留当前列表**（用户自行切换地域查看）；失败（如配额/权限不足）→ 复用现有错误提示框架展示后端 message | P2 |

### 交互细节

* 「目标地域」下拉位于克隆弹窗现有字段之内，建议顺序：名称 → 目标地域 → 负责人 → 备份负责人。
* 目标地域为必选：默认即有源地域值，不允许为空。
* 克隆成功后不自动跳转到目标地域列表。

## 业务规则

* **R-001**：克隆后安全组归属源业务（bk_biz_id 不变），地域 = 用户所选目标地域（Q1/Q2 已确认）。
* **R-002**：负责人/备份负责人默认取源安全组值，允许用户在弹窗内修改后再提交（Q2 已确认）。
* **R-003**：单次仅克隆到一个目标地域，不支持批量多地域（Q5 已确认）。
* **R-004**：目标地域下拉选项复用现有云地域字典/枚举（Q6 已确认）。
* **R-005**：克隆失败复用现有错误提示框架展示后端 message（Q7 已确认）。

## 验收标准

* **AC-001**：Given 用户打开某安全组「克隆」弹窗 When 查看 Then 弹窗含「目标地域」下拉，默认值为源安全组地域，选项覆盖当前业务可用地域全集。
* **AC-002**：Given 用户将目标地域改为其他地域并确认 When 提交克隆 Then 新安全组归属源业务、地域为目标地域，且负责人/备份负责人为用户提交值（未改则等于源值）。
* **AC-003**：Given 用户保持默认（源地域）When 提交 Then 行为与改造前一致（同地域克隆，回归项）。
* **AC-004**：Given 克隆成功 When 完成 Then 提示「已克隆至 X 地域」并停留当前列表。
* **AC-005**：Given 克隆失败 When 完成 Then 展示后端返回的错误信息（复用现有错误提示框架）。

## 边界范围

### 本期包含

* 克隆弹窗新增「目标地域」下拉（默认源地域，可选其他地域）。
* 负责人/备份负责人默认值回填源安全组，可编辑。
* 克隆结果提示与归属（源业务、目标地域）。

### 本期不包含

* 批量克隆到多个地域。
* 克隆时跨业务复制（仅源业务内跨地域）。
* 克隆后自动跳转/刷新到目标地域列表。
* 菜单入口改造（沿用现有安全组管理页面入口）。
