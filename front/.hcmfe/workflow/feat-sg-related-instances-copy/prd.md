## 背景

在安全组详情页的"关联实例"Tab 中，用户需要将关联主机的内网 IP 或主机 ID 复制出来，用于 BKCC 主机搜索、HCM 主机搜索等场景。当前页面缺少批量复制能力，用户只能逐行手动复制。

## 功能1：账号下 / 资源运营 — 勾选复制（下拉菜单）

### 用户故事

> 作为账号下 / 资源运营视图的用户，在安全组关联实例列表中，我希望能**勾选多行**并从中**复制内网IP或实例ID**，以便粘贴到主机搜索等工具中使用。

### 触发位置

安全组关联实例列表的操作栏区域（与现有"批量解绑"按钮同行）。

### 交互流程

1. 页面加载时，「复制」按钮默认**置灰**不可点击
2. 用户勾选表格中的一行或多行后，「复制」按钮**点亮**
3. 鼠标悬停「复制」按钮，**展开下拉菜单**，包含两个选项：
   - **复制内网 IP**
   - **复制实例 ID**
4. 点击任一选项：
   - 将对应字段内容复制到剪贴板
   - 弹出成功提示消息
   - 下拉菜单关闭

### 业务规则

| 规则 | 说明 |
|------|------|
| 按钮状态 | 默认置灰，勾选 ≥1 行后点亮 |
| 复制内网IP | 取勾选行的 `private_ipv4_addresses` + `private_ipv6_addresses`，以**换行符**拼接 |
| 复制实例ID | 取勾选行的 `cloud_id`，以**换行符**拼接 |
| 复制成功提示 | 使用 Message 组件提示"复制成功" |
| 跨页选择 | **必须支持跨页勾选复制**。若当前不支持跨页选择，需参照项目中已有的跨页选择方案（如 `useTableSelection` hook 或参考其他已支持跨页的列表页）实现跨页勾选能力。**同时保证现有"批量解绑"等老业务功能兼容新的跨页逻辑。** |

### 验收标准

- [ ] 未勾选时「复制」按钮置灰
- [ ] 勾选后按钮点亮
- [ ] 下拉菜单正确展开，包含"复制内网IP"和"复制实例ID"
- [ ] 复制内网IP后剪贴板内容正确（多行以换行符分隔），含 IPv4 和 IPv6
- [ ] 复制实例ID后剪贴板内容正确（cloud_id 列表以换行符分隔）
- [ ] 复制成功后弹出成功提示
- [ ] 复制后下拉菜单关闭
- [ ] 跨页勾选的所有行数据均能被正确复制
- [ ] 跨页选择的能力改动不影响现有"批量解绑"等老业务功能

## 功能2：业务下 — 一键复制（独立按钮）

### 用户故事

> 作为业务下（管理业务 / 使用业务）视图的用户，在安全组关联实例的当前业务折叠面板中，我希望**一键复制当前业务下全部关联实例的内网IP或主机ID**，无需勾选操作，以便快速获取当前业务下的主机信息。若接口分页，需拉取全部数据。

### 触发位置

当前业务折叠面板的 `.tools` 工具栏区域。

### 交互流程

1. 在**当前业务**（`isCurrentBusiness = true`）的折叠面板工具栏中，显示两个独立按钮：
   - 「复制内网IP」
   - 「复制主机ID」
2. 非当前业务的面板**不显示**这两个按钮
3. 当前业务下没有关联实例数据时，按钮**置灰**
4. 点击按钮：
   - 将当前业务列表**当前页全部数据**的对应字段复制到剪贴板
   - 弹出成功提示消息

### 业务规则

| 规则 | 说明 |
|------|------|
| 显示条件 | 仅 `isCurrentBusiness = true` 的面板显示 |
| 按钮状态 | 数据为空时置灰，有数据时可点击 |
| 数据范围 | 当前业务下**全部列表数据**（不依赖勾选），若接口分页则需 `rollRequest` 拉取全部 |
| 复制内网IP | 取全部数据的 `private_ipv4_addresses` + `private_ipv6_addresses`，以**换行符**拼接 |
| 复制主机ID | 取全部数据的 `cloud_id`，以**换行符**拼接 |
| 复制成功提示 | 使用 Message 组件提示"复制成功" |

### 验收标准

- [ ] 当前业务折叠面板工具栏显示"复制内网IP"和"复制主机ID"两个按钮
- [ ] 非当前业务面板不显示这两个按钮
- [ ] 无数据时按钮置灰
- [ ] 有数据时按钮可点击
- [ ] 点击"复制内网IP"后剪贴板包含当前业务下**全部**内网IP（含 IPv4 + IPv6），换行分隔，分页时已拉取全部页数据
- [ ] 点击"复制主机ID"后剪贴板包含当前业务下**全部** cloud_id，换行分隔，分页时已拉取全部页数据
- [ ] 复制成功后弹出成功提示
- [ ] 接口分页场景下正确使用 rollRequest 拉取全部数据

## 两个功能的差异对照

| 维度 | 功能1（账号下/资源运营） | 功能2（业务下） |
|------|------------------------|----------------|
| 触发方式 | 下拉菜单 | 独立按钮 |
| 依赖勾选 | ✅ 依赖 | ❌ 不依赖 |
| 数据范围 | 勾选行 | 全部数据（若分页需 rollRequest） |
| 跨页支持 | ✅ 必须支持（若当前不支持需实现） | ❌ 不涉及 |
| 显示条件 | 始终显示（置灰控制） | 仅当前业务 |

- 消息提示使用项目统一的消息组件
