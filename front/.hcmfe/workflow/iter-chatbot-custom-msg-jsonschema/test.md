# 测试验证清单 — iter-chatbot-custom-msg-jsonschema

> 范围：jsonschema 模式基础框架 + 云账号选择场景。仅覆盖本次改动，不回归整个 chatbot 模块。
> 入口：海垒 AI 助手对应业务的测试环境地址（全页 chatbot 页 + 浮窗 AI 助手两种形态）。
> 敏感数据用占位符，例如 `<test_account>`。

## 数据准备

- 一个可触发主机申领、会下发 `CUSTOM(account_select.interrupt)` 的会话（agent 侧已配置）。
- 选项中至少包含：1 个 `enabled:true` 可选账号、1 个 `enabled:false` 且带 `reason` 的不可选账号。
- 一段含历史已选账号的会话（用于历史回放只读态）。

## P0（必过）

| # | 用例 | 期望结果 |
|---|---|---|
| P0-1 | 发起主机申领，agent 下发账号选择 | 提示语作为普通文本气泡渲染；其下渲染厂商选择卡片，按 `options` 列出账号 |
| P0-2 | 选中一个可选账号并点「确认」 | 卡片进入收起摘要态「您已选择【厂商名】- 账号名」；上行请求 `forwardedProps.resumeValue` = 所选 `account_id` |
| P0-3 | 不可选账号（`enabled:false`） | 不可点击选中；hover 显示 `reason` tooltip |
| P0-4 | 确认后查看顶部 | 出现吸顶回显条「云账号：【厂商名】- 账号名」，通栏铺满主内容区，不随消息滚动 |

## P1（重要）

| # | 用例 | 期望结果 |
|---|---|---|
| P1-1 | 点击收起摘要行 | 展开为只读态，可见所有厂商卡（选中项高亮带角标），再次点击可收起 |
| P1-2 | 刷新 / 重新进入含历史选择的会话 | 卡片还原为只读态，正确高亮历史所选账号；吸顶回显正确 |
| P1-3 | 浮窗模式查看卡片 | 卡片为 1px 描边、图标与间距更紧凑、厂商卡单列整行 |
| P1-4 | 全页模式查看卡片 | 卡片为投影无描边；厂商卡多列、换行时靠左对齐等宽 |
| P1-5 | 浮窗模式 hover 消息操作按钮（复制/重新生成） | tooltip 浮于面板之上，不被遮挡 |
