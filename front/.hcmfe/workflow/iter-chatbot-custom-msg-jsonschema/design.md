## 0. 本子需求范围

| 在本迭代内 | 不在本迭代内 |
|------------|--------------|
| jsonschema 选项选择卡片**基础框架**（agent 下发 schema → 渲染选择卡 → 选择回传，泛化 HITL；收起/展开/只读回显为框架通用交互，QD1） | 复杂多字段表单 / 只读信息卡片（→ 指令模板模式） |
| **云账号选择**真实场景（首个接入）：厂商卡单选、收起态、展开只读回显、吸顶回显（全页+浮窗，QD2） | 调接口实时拉取选项的业务联动选择器（→ 指令模板模式） |
| 提交后只读、历史回放只读、未提交中断只读空态 | 各场景后续会话流程 / HITL 内部交互（沿用 agent 现有能力） |
| 单账号场景跳过该步骤 | **多选 / 自定义输入的实际落地**（框架预留能力，本迭代云账号仅单选，QD3） |

对齐 PRD：`prd.md` §1～§6、§3.4。

> 稿面来源：用户提供的 2 张 PNG —— ① 全页模式云账号选择交互说明（选择态 / 收起态 / 展开只读态 + 4 条 note）；② 浮窗（ai-assistant 内嵌）模式云账号选择。

## 0.1 横切设计原则（重要）

**所有"选项式渲染"都必须同时适配两种载体**（用户强调）：

| 载体 | 宽度 | 选项布局 |
|------|------|----------|
| **全页 chatbot**（宽） | 主内容区较宽 | 选项呈**横向卡片**一排，超出**自动换行**（QD5） |
| **浮窗 ai-assistant**（窄） | 窗口内容区较窄 | 选项呈**纵向整行**铺满宽度，每行含 vendor 图标 + 厂商名/账号名 + 右侧附加信息（如配额） |

即同一份 jsonschema 选项数据，需**响应式**在宽容器（卡片横排）与窄容器（整行纵排）下都正确渲染。

## 2. 信息架构 / 布局

### 2.1 云账号选择 —— 选择态（初始）

```
┌─ 云账号选择卡（对话内自定义消息）──────────────────────────┐
│ ☁ 已进入主机申领模式。请先选择需要操作的云账号            │  ← 头部提示语
│                                                            │
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐        │
│ │☁ 自研云    ✔│ │☁ 腾讯云      │ │a AWS         │        │  ← 一排厂商卡
│ │  ieg-ziyan   │ │  test-account│ │  global-prod │        │
│ └──────────────┘ └──────────────┘ └──────────────┘        │
│   （选中：蓝框+右上角打勾角标）                            │
└────────────────────────────────────────────────────────────┘
```

- **头部提示语**：左侧云图标（蓝）+ 文案「已进入主机申领模式。请先选择需要操作的云账号」（文案由 agent 下发）。
- **厂商卡（option item）**：横向一排，每张含 **左侧厂商图标** + 右侧上下两行（**厂商名**加粗 + **账号名**弱色）。如：自研云/ieg-ziyan、腾讯云/test-account、AWS/global-prod。
- **选中态**：选中卡 **蓝色边框** + **右上角三角打勾角标**。
- 单选：同一时刻仅一张选中。

### 2.2 收起态（选中并提交后）

```
┌────────────────────────────────────────────────────────────┐
│ ✓ 您已选择【自研云】- ieg-ziyan                        ⌄    │  ← 整行可点击展开
└────────────────────────────────────────────────────────────┘
```

- 绿色对勾 + 摘要文案「您已选择【自研云】- ieg-ziyan」+ 右侧**展开箭头 `⌄`**。
- 选中后选择栏**自动收起**为此摘要行；卡片标题区 icon 由「☁」变为**打勾**态（note 2）。

### 2.3 展开只读态（点击收起态整行）

```
┌────────────────────────────────────────────────────────────┐
│ ✓ 您已选择【自研云】- ieg-ziyan                        ⌃    │  ← 整行可点击收起
│ ┌──────────────┐ ┌──────────────┐ ┌──────────────┐         │
│ │☁ 自研云    ✔│ │☁ 腾讯云      │ │a AWS         │         │  ← 只读回显
│ │  ieg-ziyan   │ │  test-account│ │  global-prod │         │
│ └──────────────┘ └──────────────┘ └──────────────┘         │
└────────────────────────────────────────────────────────────┘
```

- 点击收起态整行 → **展开回显**之前选择的厂商卡（已选项保持选中角标）。
- 展开后箭头变 `⌃`（可再收起）。
- **只读**：选中后不支持交互、**无 hover 效果**、**不允许切换选择**（note 3）。

### 2.4 顶部吸顶回显（选择云账号后）

- 选择云账号后展示一条选择结果回显条，**吸顶展示**（不随对话/页面滚动）（note 4）。内容为已选云账号摘要（如「自研云 - ieg-ziyan」）。
- **范围（QD2 确认）**：凡涉及云账号选择的场景都支持吸顶回显，且**两端**都要：
  - **全页 chatbot**：吸顶在**主内容区顶部**。
  - **浮窗（ai-assistant 内嵌）**：吸顶在**窗口内容区顶部**。
- 吸顶回显与"云账号已选"语义绑定（非所有 jsonschema 选择都出吸顶，仅云账号选择类）。

### 2.5 浮窗（ai-assistant 内嵌）模式布局

> 来源：用户提供的浮窗模式 PNG。

```
┌─ AI助手浮窗 ─────────────────┐
│ ☁ 请选择需要操作的云账号       │  ← 头部提示语
│ ┌─────────────────────────┐ │
│ │☁ 自研云          配额 8200│ │  ← 纵向整行（铺满宽度）
│ │  ieg-ziyan               │ │
│ ├─────────────────────────┤ │
│ │☁ 腾讯云          配额 1500│ │  ← hover 态（浅灰底）
│ │  test-account            │ │
│ ├─────────────────────────┤ │
│ │a AWS             配额 300 │ │
│ │  global-prod             │ │
│ └─────────────────────────┘ │
└──────────────────────────────┘
```

- **纵向整行**：浮窗较窄，选项铺满宽度纵向排列（区别于全页横向卡片）。
- **行内容**：左 vendor 图标 + 厂商名（加粗）/ 账号名（弱色）+ **右侧配额**（如「配额 8200」）。
- **hover 态**：未选择前行可 hover（浅灰底 + 可点击指针）；选中/只读后无 hover（对齐 note 3）。
- 收起态 / 展开只读态 / 吸顶回显同全页逻辑，吸顶位置在**窗口内容区顶部**（QD2）。

> **选项附加信息（数据驱动）**：选项可携带**附加信息**（如云账号的**配额**）。是否展示**由 schema/agent 下发的数据决定**（QD6 确认）：选项数据携带配额 → **全页 + 浮窗两端都展示**；未携带 → 不展示。字段约定见 api 阶段 QD-Schema。

## 3. 关键交互

### 3.1 单账号场景跳过（note 1）

- 若该场景只有 1 个云账号，**不展示**云账号选择步骤，直接进入下一步骤。

### 3.2 选择 + 提交 + 收起（note 2）

- 用户点选某厂商卡 → 该卡呈选中态（蓝框 + 打勾角标）。
- 提交后：选择栏**自动收起**为收起态摘要行（§2.2），标题 icon 变打勾。
- 提交：选择结果序列化后复用 `/agui` 作为用户消息回传 agent（对齐 HITL，载体细节见 api 阶段）。

### 3.3 展开 / 收起回显（note 3）

- 收起态点击整行 → 展开只读回显（§2.3）；再点收起。
- 只读：无 hover、不可切换、不可重新提交。

### 3.4 吸顶回显（note 4）

- 选择后顶部标题栏下方出现吸顶回显条，常驻不随滚动。

### 3.5 历史回放

- 已提交：渲染为收起态摘要行（可展开只读回显）。
- 未提交即中断：展示为只读空态（展示选项但不可操作），对齐 HITL readonly。

## 4. 状态流转

```
agent 下发云账号选择 jsonschema 消息
  → 单账号？ 是 → 跳过此步，直接下一步
            否 ↓
  → 选择态：头部提示语 + 一排厂商卡（可点选）
  → 用户点选某厂商卡（蓝框+角标）→ 提交
  → 提交后：选择栏自动收起为摘要行；标题 icon → 打勾；顶部出现吸顶回显
  → 收起态：点击整行 → 展开只读回显（不可切换）→ 再点收起
历史回放：已提交 → 收起态（可展开只读）；未提交中断 → 只读空态
```

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 单账号场景 | 不展示选择步骤，直接下一步 |
| 多账号选择态 | 展示厂商卡一排，可点选单个 |
| 已提交 | 收起态摘要行 + 可展开只读回显 + 顶部吸顶回显 |
| 展开只读 | 厂商卡只读（无 hover、不可切换） |
| 未提交即中断（历史回放） | 只读空态（展示选项不可操作） |
| 厂商卡数量较多 | 一排排布；超出换行/横向处理（稿面默认 3 个；具体溢出规则见 §8 QD5） |
