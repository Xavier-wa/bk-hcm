# Test - 负载均衡-名称支持英文点号

## 前提

- 后端已放开 CLB 名称点号（story 后端部分已上线/联调环境已含该改动）。

## P0（核心）

- [ ] 主账号入口：`负载均衡 → 新建（CLB 申请）`，名称填入 `abc.def`，提交成功，无校验拦截。
- [ ] 名称填入 `a.b.c`，提交成功。
- [ ] 名称填入 `中文.name`，提交成功。
- [ ] 名称填入 `.abc`（点号开头），前端提示校验失败，无法提交。
- [ ] 名称填入 `abc.`（点号结尾），前端提示校验失败，无法提交。

## P1（边界）

- [ ] 名称长度为 60 字符、中间含点号，提交成功。
- [ ] 名称长度 61 字符，前端提示校验失败。
- [ ] 名称含连续点号 `a..b`，提交成功（正则允许，符合 story「名称中间可出现点号」）。
- [ ] 名称仅含点号 `.`，前端校验失败。

- [ ] 编辑已有 CLB 实例名称、加入点号后保存成功。
