# Coding - 负载均衡-名称支持英文点号

## 背景

TAPD story_1069995598136645087：后端放开负载均衡（CLB）实例名称中的英文点号（`.`）后，
前端申领表单的名称校验正则仍只支持中文/字母/数字/`-`，会拦截带点号的名称，导致后端放开在 UI 上不可用。
本期在前端同步放开点号（对应 story 正文 Q-002 待确认风险）。

## 改动文件

- `front/src/views/service/service-apply/clb/hooks/useRenderForm.tsx`
  - `rules.name` 校验器（原 L152–154）

## 改动点

### 1. 名称校验正则放开点号

```diff
- /^(?=.{1,60}$)[\u4E00-\u9FA5A-Za-z0-9]([\u4E00-\u9FA5A-Za-z0-9-]*[\u4E00-\u9FA5A-Za-z0-9])?$/
+ /^(?=.{1,60}$)[\u4E00-\u9FA5A-Za-z0-9]([\u4E00-\u9FA5A-Za-z0-9.-]*[\u4E00-\u9FA5A-Za-z0-9])?$/
```

仅在中部字符类中加入 `.`（`[\u4E00-\u9FA5A-Za-z0-9.-]`，其中 `-` 位于字符类末尾为字面量）。

### 2. 校验提示文案同步

```diff
- '60个字符，支持中文、字母、数字、“-”，且必须以中文、字母、数字开头和结尾。'
+ '60个字符，支持中文、字母、数字、“-”与“.”，且必须以中文、字母、数字开头和结尾。'
```

## 行为说明（前后对比）

| 名称样例 | 改前 | 改后 |
|---------|------|------|
| `abc.def` | 拒绝 | 通过 |
| `a.b` | 拒绝 | 通过 |
| `中文.name` | 拒绝 | 通过 |
| `.abc`（点号开头） | 拒绝 | 拒绝（首尾仍须为中文/字母/数字） |
| `abc.`（点号结尾） | 拒绝 | 拒绝 |
| `a--b` | 通过 | 通过 |
| 61 个字符 | 拒绝 | 拒绝（长度 1–60 不变） |

## 影响范围

- 前端仅 `useRenderForm.tsx` 这一处 CLB 名称校验拦截点号（`business/forms/security/index.vue` 的同类正则是安全组名称，与本 story 无关）。
- 仅放开创面申领（主账号入口）名称校验；编辑/其他入口若复用同一 `rules.name` 则一同生效，无需额外改动。

## 风险点

- 仅前端放开，后端已由本 story 后端部分放开；若后端未上线，前端放行后提交仍可能被后端拒绝（接口报错）。
  联调需确认后端版本已包含放开。
- 未新增 `required` 校验（沿用既有行为，空值走格式提示），非本期范围。
