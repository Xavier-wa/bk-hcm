# Design：aiagent · chatbot 聊天窗模式

> 已通过用户提供的 PNG 识别稿面（Figma MCP 本月额度用尽，降级用图）。冲突以稿面 + 用户确认为准。
> 形态完全参照 `@blueking/ai-blueking` 的悬浮球 + 聊天窗面板。

## 0. 本子需求范围

| 在本迭代内 | 不在本迭代内 |
|------------|--------------|
| 悬浮球入口（参照 ai-blueking） | 划词唤起（AiSelection） |
| 聊天窗**窗口 UI 与交互**（标题栏/拖拽/缩放/收起/关闭/悬浮球） | 新的对话内容渲染器（表单/表格/工具卡片沿用现网） |
| 面板可拖拽、可缩放 | 全页 chatbot 的重构/下线 |
| 与全页共享会话 + 跨形态联动自动唤起 | 主机申领之外的业务场景内容 |
| 以页面级可配置/可导入通用组件提供 | 后端 agent 接口契约改动 |
| 图标从 ai-blueking 源码搬运 | 聊天框能力（输入/上传/消息渲染）自研 → 直接复用 chat-x |

### 0.1 实现取向（用户补充，强约束）

- **聚焦窗口的 UI 与交互能力**；所有功能**严格参照 `@blueking/ai-blueking`** 组件。
- **聊天框内能力不自研**：输入框、上传附件、消息展示等**与全页一致，直接使用 `@blueking/chat-x` 组件**（沿用现网 `views/chatbot` 的接入方式）。
- **图标**：需求涉及的 icon **可直接从 ai-blueking 源码搬运到项目**（详见 §3.x 落地策略）。

## 2. 信息架构 / 布局

### 2.1 两种形态并存

- **全页模式（现网保留）**：`/business/chatbot`，HCM 业务布局内嵌左会话侧栏 + 右对话区。
- **聊天窗模式（本迭代新增）**：悬浮球 + 浮于当前页面之上的聊天窗面板，参照 ai-blueking。

### 2.2 聊天窗面板结构（自上而下）

| 区域 | 内容 |
|------|------|
| 标题栏 | 左：AI 助手图标 + 标题「AI助手」；右：操作图标组（缩小高度/恢复默认尺寸、会话历史、更多、收起、关闭，参照 ai-blueking） |
| 会话内容区 | 复用现网渲染：消息流、工具调用折叠块（「已调用 N 个工具」「思考了 N 秒」）、方案推荐表、告警条、表单态、申请记录等 |
| 输入区 | 输入框（占位「请输入问题，Shift+Enter 换行」）+ 附件入口 + 模型选择下拉 + 发送 |

### 2.3 浮窗形态

- 悬浮球**默认右下停靠、可隐藏/复显**（参照 ai-blueking）。
- 面板默认**右侧停靠**浮窗，白底、大圆角、阴影。
- **可拖拽**移动位置、**可缩放**调整大小（参照 ai-blueking 默认）。
- 标题栏「缩小高度/恢复默认尺寸」切换面板高度（参照 ai-blueking，非全屏、不跳全页）。
- 浮于当前页面内容之上，不破坏宿主页面布局。
- 悬浮球 ↔ 面板：点击悬浮球展开面板；标题栏收起/关闭回到悬浮球态。

### 2.4 交付形态（通用组件）

- 以**页面级、可配置/可导入**的通用组件提供；接入方在页面/布局按需挂载。
- **每页独立实例**：不同页面各自挂载自己的实例，前端展开/尺寸/位置等 UI 状态各页独立；**仅后端会话数据共享**（同一会话空间，互通）。

## 3. 关键交互

1. **唤起 / 收起 / 关闭**
   - 点击悬浮球 → 展开聊天窗面板。
   - 标题栏「收起」→ 回到悬浮球（保留当前会话上下文，再次唤起不丢失）。
   - 标题栏「关闭」→ 关闭面板回到悬浮球态。
2. **拖拽 / 缩放**
   - 面板可拖拽移动；边缘可缩放调整尺寸。
3. **会话管理（复用现网）**
   - 通过标题栏「会话历史」入口查看/切换/新建会话。
   - 会话数据与全页**共享同一会话空间**，两端互通。
4. **对话（复用现网）**
   - 流式输出、工具调用过程展示、思维链、HITL 人工介入、markdown/表格/表单渲染，行为与全页一致。
5. **跨形态会话联动（核心新增）**
   - 在**全页模式**对话中点击方案卡的「**添加到配置清单**」→ 路由跳转到**主机申领页面**。
   - 跳转后该页面**自动唤起聊天窗**，并**自动加载来源会话**（与全页同一 session）。
   - 用户在聊天窗内延续同一段对话。

## 4. 状态流转

```
悬浮球态 ──点击悬浮球──▶ 面板展开态
面板展开态 ──收起/关闭──▶ 悬浮球态（会话上下文保留）
面板展开态 ──拖拽/缩放──▶ 面板展开态（位置/尺寸变化）

[全页对话] ──点击「添加到配置清单」──▶ 路由跳转主机申领页
主机申领页加载 ──自动唤起聊天窗 + 加载来源会话──▶ 面板展开态（延续会话）
```

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 库存不足等业务告警 | 会话内告警条（复用现网渲染，如「SA3.4XLARGE32 库存充足，可替代您提单的机型」提示样式） |
| 生成中 | 流式输出 + 停止能力（复用现网） |
| 联动跳转后会话不存在/无权限 | 唤起**空面板/新会话**并给出提示（D2） |
| 多页面/多次唤起 | 每页独立前端实例，后端会话共享（D1） |

## 8. 已确认决策

- D1 **每页独立前端实例**：不同页面各自挂载实例，UI 状态（展开/尺寸/位置）各页独立；仅后端会话数据共享。
- D2 **联动异常降级**：跳转主机申领页后若来源会话不存在/无权限，唤起空面板/新会话并提示。
- D3 **悬浮球**默认**右下停靠、可隐藏/复显**（参照 ai-blueking）。
- D4 **标题栏右1 图标 = 缩小高度/恢复默认尺寸**（参照 ai-blueking），非全屏、不跳全页。
