# PRD: 自研云-主机申领-网络信息增加压测子网配置类型

> 关联 TAPD: [1069995598135009392](https://<TAPD_HOST>/tapd_fe/my/work?dialog_preview_id=story_1069995598135009392)

## 背景

自研云主机申请页面，"增加资源需求"/"修改资源需求"弹窗中的「网络信息」区域目前只有 VPC 和子网两个选择器，用户无法区分普通申请和压测申请。当新增压测子网类型后，需要提供配置类型选择，让用户明确声明本次申请是自动匹配还是用于压测，并据此展示不同的 VPC/子网列表。

## 改动范围

本次需求涉及两组弹窗场景，共用同一个 `NetworkInfoCollapsePanel` 组件：

| 场景                        | 页面路径                                                           | 网络信息块位置 |
| --------------------------- | ------------------------------------------------------------------ | -------------- |
| 增加资源需求 — 实例配置     | `ziyanScr/hostApplication/components/application-form/index.tsx`   | 弹窗侧边栏中   |
| 修改申请页 — 未生产需求调整 | `ziyanScr/hostApplication/components/application-modify/index.vue` | 弹窗侧边栏中   |

> 两处均复用同一个 `network-info-collapse-panel/index.vue` 组件，**改动聚焦于此组件及其两个调用方即可**。
>
> 第三处引用 `cvm-produce/component/create-order/index.vue` **不在本次需求范围内**。

## 用户故事

### US1: 选择配置类型

**作为** 自研云主机申请人  
**我想要** 在网络信息区域选择「自动匹配」或「用于压测」  
**以便** 明确本次申请的用途类型，获取对应的可用网络资源列表

#### 验收标准

- [ ] 网络信息面板展开后，在 VPC 选择器上方显示一组 Radio 按钮：「自动匹配」和「用于压测」
- [ ] 默认选中「自动匹配」
- [ ] 两个选项互斥，切换时 VPC 和子网已选值清空
- [ ] 「自动匹配」为常规申请场景，「用于压测」为压测专用场景

---

### US2: 网络信息标题行提示（参考设计稿）

**作为** 自研云主机申请人  
**我想要** 在网络信息面板标题行看到提示图标和文本  
**以便** 在未展开面板时也能了解当前网络配置的说明

#### 验收标准

- [ ] 网络信息标题文本右侧新增提示图标 + 固定文本
- [ ] 提示内容为固定文案：`[VPC] 与 [子网] 均默认系统自动匹配，若需用于压测场景可手动切换`
- [ ] 折叠状态和展开状态标题提示保持一致
- [ ] 不根据配置类型动态变化，为固定说明性文案

---

### US3: 自动匹配模式下的 VPC/子网列表

**作为** 自研云主机申请人  
**我想要** 在自动匹配模式下查看完整的 VPC 列表和排除了压测专用项的子网列表  
**以便** 在自动匹配场景下看到全部可用 VPC，同时避免误选压测专用子网

#### 验收标准

- [ ] 选择「自动匹配」后，VPC 列表展示全部 VPC（不排除压测专用 VPC）
- [ ] 选择「自动匹配」后，子网列表排除压测专用子网
- [ ] 排除逻辑：同时请求原有接口和压测接口，从原接口返回结果的子网中过滤掉压测接口返回的子网；VPC 不做排除
- [ ] 原有的 BCS/容器网络提示逻辑保持不变

---

### US4: 用于压测模式下的 VPC/子网列表

**作为** 自研云主机申请人  
**我想要** 在用于压测模式下只看到压测专用的 VPC 和子网列表  
**以便** 快速选择可用的压测网络资源

#### 验收标准

- [ ] 选择「用于压测」后，VPC 列表仅展示后端压测接口返回的 VPC
- [ ] 选择「用于压测」后，子网列表仅展示后端压测接口返回的子网
- [ ] VPC 和子网的展示格式与自动匹配模式一致（`ID | Name`），**不展示网段、来源账号，无预览按钮**

---

### US4.1: 用于压测选项的可用性控制

**作为** 自研云主机申请人  
**我想要** 在当前地域没有压测子网时，「用于压测」选项不可用  
**以便** 避免选择一个没有可用资源的配置类型

#### 验收标准

- [ ] 进入面板时（region 变化时）预请求压测接口获取可用性
- [ ] 当压测接口返回数据为空或长度为 0 时，禁用「用于压测」Radio 选项
- [ ] 禁用时通过 `v-bk-tooltips` 展示提示：`当前地域无压测子网`
- [ ] 禁用状态下用户无法切换到「用于压测」

---

### US5: 压测子网使用提示

**作为** 自研云主机申请人  
**我想要** 在用于压测模式下看到压测子网的使用须知  
**以便** 了解压测子网的使用限制和注意事项

#### 验收标准

- [ ] 选择「用于压测」时，在子网选择器下方展示压测使用须知
- [ ] 须知内容包含以下要点：
  - 独立出口：使用专用 NAT 及出口 IP，请注意安全组、防火墙策略配置
  - 禁止生产：本子网不建议正式业务部署，仅供压测使用
  - 及时释放：压测结束请立即切换子网，避免占用压测配额
- [ ] 切换到「自动匹配」时须知隐藏

---

### US6: 修改资源需求场景 + 配置类型自动推断

**作为** 自研云主机申请人  
**我想要** 在修改已有资源需求时，网络信息面板根据已选的 VPC/子网自动识别配置类型  
**以便** 无需手动切换即可看到匹配的配置模式

#### 验收标准

- [ ] 配置类型为纯前端字段，后端不保存
- [ ] 修改资源需求弹窗打开时，VPC 和子网按原有逻辑回填（基于已保存的 vpc_id / subnet_id）
- [ ] **自动推断逻辑**：同时请求原接口和压测接口获取两份列表后，判断已回填的 VPC/子网值落在哪个列表中：
  - 若当前 VPC **或** 子网值在压测接口返回的列表中 → 自动将配置类型设为「用于压测」
  - 否则（包括无回填值的情况）→ 配置类型设为「自动匹配」
- [ ] 推断完成后，VPC/子网选择器的列表与推断结果一致（压测模式的列表能匹配到当前回填值）
- [ ] 用户可手动切换配置类型（与新增场景行为一致：切换时清空已选值）

## 设计稿参考要点

> 以下信息来自 TAPD 设计稿截图确认

1. **标题行**: 「网络信息」带编号图标 + 提示图标 + 文本 `[VPC] 与 [子网] 均默认系统自动匹配，若需用于压测场景可手动切换`
2. **配置类型**: 位于 VPC 上方，Radio 按钮组「自动匹配」/「用于压测」，必填标记（红色星号），默认选中「自动匹配」
3. **VPC / 子网选择器**: 展示格式 `ID | Name`，**不需要展示网段、来源账号，不需要预览按钮**
4. **红色文字部分为产品描述，非 UI 元素**

## 边界场景

| 场景                                     | 处理方式                                                                                                              |
| ---------------------------------------- | --------------------------------------------------------------------------------------------------------------------- |
| 用户切换配置类型                         | 清空已选 VPC 和子网，重新加载对应列表                                                                                 |
| 压测接口返回空列表/长度 0                | 禁用「用于压测」Radio，`v-bk-tooltips` 提示「当前地域无压测子网」                                                     |
| 自动匹配模式下原接口和压测接口返回有重叠 | VPC 列表展示全部结果（不做排除）；子网列表从原接口结果中排除压测项                                                    |
| 自动匹配模式下压测接口请求失败           | 降级处理：展示原接口全部结果（不排除），不影响用户正常使用                                                            |
| 用于压测模式下压测接口请求失败           | VPC 和子网下拉列表为空，显示无可用资源提示                                                                            |
| 配置类型字段                             | 纯前端状态，后端不保存；弹窗打开时根据已回填的 VPC/子网值在哪个接口列表中自动推断配置类型；无回填值时默认「自动匹配」 |
| 网络信息面板禁用时                       | 不显示配置类型 Radio，保持原有禁用行为                                                                                |
