## 2. UI 交互设计

### 2.1 网络信息面板标题行

**折叠状态**（始终可见）：

```
▶ 网络信息  ℹ [VPC] 与 [子网] 均默认系统自动匹配，若需用于压测场景可手动切换   VPC：xxx  子网：xxx
```

**展开状态**：

```
▼ 网络信息  ℹ [VPC] 与 [子网] 均默认系统自动匹配，若需用于压测场景可手动切换
```

**交互要点**：
- 标题文本「网络信息」加粗，颜色 #313238
- 提示图标使用 `hcm-icon bkhcm-icon-info-line` 类
- 提示文本固定为 `[VPC] 与 [子网] 均默认系统自动匹配，若需用于压测场景可手动切换`，不随配置类型动态变化
- 提示文本字号 12px，颜色 #979ba5，最大宽度 400px，超长省略
- 折叠状态下标题行右侧展示已选 VPC/子网概览，未选时显示「系统自动分配」
- 折叠/展开标题行提示保持一致

---

### 2.2 配置类型 RadioButton

位于 VPC 选择器上方，面板展开内容区顶部：

```
配置类型 *  [自动匹配] [用于压测]
```

**交互要点**：
- 使用 `bk-radio-button` 按钮样式（非圆点样式）
- 表单项带红色必填标记 `*`
- 默认选中「自动匹配」
- 两个选项互斥
- 切换时清空已选 VPC 和子网
- 「用于压测」禁用时灰色不可点击，悬停 tooltip 显示「当前地域无压测子网」
- 面板禁用（`disabled`）时不显示配置类型 Radio

---

### 2.3 VPC / 子网选择器

**两种模式下列表内容不同**：

| 配置类型 | VPC 列表 | 子网列表 |
|---------|----------|---------|
| 自动匹配 | 展示全部 VPC（不排除压测 VPC） | 排除压测专用子网 |
| 用于压测 | 仅展示压测专用 VPC | 仅展示压测专用子网 |

**展示格式**：
- 统一为 `ID | Name` 格式
- 不展示网段、来源账号、无预览按钮
- 原有的 BCS/容器网络提示逻辑保持不变（VPC/子网名含 BCS 或 OVERLAY 时展示容器网络提示）

---

### 2.4 压测子网使用须知

仅在「用于压测」模式下展示，位于配置类型 Radio 和 VPC 选择器之间：

```
⚠ 压测子网使用须知
  • 独立出口：使用专用 NAT 及出口 IP，请注意安全组、防火墙策略配置
  • 禁止生产：本子网不建议正式业务部署，仅供压测使用
  • 及时释放：压测结束请立即切换子网，避免占用压测配额
```

**交互要点**：
- 使用 `bk-alert` 组件，类型 `warning`
- 切换到「自动匹配」时须知隐藏
- 须知内容为固定文案

---

### 2.5 修改场景自动推断

**交互流程**：

1. 用户打开「修改资源需求」弹窗
2. VPC/子网按原有逻辑回填（基于已保存的 vpc_id / subnet_id）
3. 用户展开网络信息面板时，系统自动判断回填值是否属于压测资源
4. 若回填的 VPC **或** 子网落在压测接口返回的列表中 → 自动选中「用于压测」
5. 否则（包括无回填值）→ 自动选中「自动匹配」
6. 推断完成后用户仍可手动切换配置类型

---

### 2.6 状态流转

```
面板关闭 ──展开──▶ 面板展开
                     │
                     ├─ 有回填值 ──▶ 自动推断配置类型 ──▶ 展示对应列表
                     │
                     └─ 无回填值 ──▶ 默认「自动匹配」 ──▶ 展示完整 VPC / 排除压测子网
                                                           │
                                            切换配置类型 ──▶ 清空已选值 ──▶ 展示对应列表
```

## 3. 边界交互

| 场景 | 交互表现 |
|------|---------|
| 当前地域无压测子网 | 「用于压测」RadioButton 禁用 + tooltip「当前地域无压测子网」 |
| 压测接口请求失败 | 降级为自动匹配模式，VPC/子网列表展示全部原始数据，压测选项禁用 |
| 用户切换配置类型 | 已选 VPC 和子网清空，列表按新模式刷新 |
| region 切换 | 若新 region 无压测配置且当前在「用于压测」模式，自动切回「自动匹配」 |
| 面板禁用 | 不显示配置类型 Radio，保持原有禁用行为 |
