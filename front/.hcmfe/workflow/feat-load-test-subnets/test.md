## 数据准备

| 准备项 | 说明 |
|--------|------|
| 含压测子网的地域 | 选择 `load_test_subnets` 返回中存在的 region（如 `ap-nanjing`） |
| 无压测子网的地域 | 选择 `load_test_subnets` 返回中不存在的 region |
| 修改场景数据 | 准备一份已保存的 vpc_id + subnet_id 为压测资源的主机申领记录 |
| 修改场景数据（普通） | 准备一份已保存的 vpc_id + subnet_id 为普通资源的主机申领记录 |
