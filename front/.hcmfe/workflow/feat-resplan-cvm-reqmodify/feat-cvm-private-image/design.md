# Design: 自研云-主机申领-私有镜像支持

## 概述

本次需求**无 UI 变更**。镜像选择器的外观、布局、样式、交互动画完全保持原样。

## 现有镜像选择器 UI（保持不变）

### 组件位置
- 自研云主机申领页面 → 实例配置区域 → 镜像选择器
- 自研云购买主机页面 → 实例配置区域 → 镜像选择器

### 外观描述
- 触发方式：下拉选择框（点击展开镜像列表）
- 列表项：每项显示镜像名称 + OS 类型等基本信息
- 选中态：选中后回填镜像名称到输入框

### 交互行为（改造前后一致）

| 用户操作 | 系统响应 |
|----------|----------|
| 点击镜像选择器 | 展开下拉列表，展示可用镜像 |
| 在列表中点击某镜像 | 选中该镜像，关闭下拉框，回填名称 |
| 切换地域后再打开 | 镜像列表按新地域刷新 |
| 无可用镜像时 | 下拉列表为空或显示兜底文案 |

### 改造前后差异

**视觉层面：无差异**

唯一变化是下拉列表中的**数据内容**可能多出若干私有镜像选项（对非目标业务用户完全无感知）。
