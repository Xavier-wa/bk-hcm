## 验证范围

- 功能边界: 安全组管理页三个 tab（安全组 / GCP 防火墙 / 参数模板）的综合查询条件项与资源接入对齐；业务视角直接进入即可用，不依赖先访问资源接入；业务视角安全组 tab 不展示使用业务 / 管理业务；默认管理类型回填与列表请求 filter 保持现网语义。
- 不在范围: 主机 / VPC 等其它资源列表的 `useFilter.searchData` 闸门；新增资源接入该 tab 尚不存在的条件；助手误判话术。

  - 业务视角准备至少一个可查看的业务，以及名称可区分的安全组 / 参数模板数据
  - GCP 防火墙 tab 需有 GCP 相关数据或至少能展开条件项
  - 资源接入视角准备「全部云厂商」入口，便于对照条件项；再测侧栏选中具体云厂商 / 账号时条件项是否正确隐藏云厂商 / 云账号 ID

### P0 - 主流程（必测）

| ID | 场景 | 前置 | 操作 | 期望 | 回滚 |
|----|------|------|------|------|------|
| P0-01 | 业务视角直接进入安全组列表 | 清空站点数据；从未访问资源接入 | 打开业务视角安全组列表，展开综合查询 | 条件含：安全组 ID、名称、云厂商、云账号 ID、管理类型、地域；**不含**使用业务、管理业务 | 无 |

| P0-03 | 按名称搜索安全组 | 业务视角安全组列表；存在名称可匹配的数据 | 选择「名称」，输入已有安全组名称的部分关键词并搜索 | 列表仅展示名称包含该关键词的安全组；请求对 `name` 为包含（CS） | 清空条件 |
| P0-04 | 展开云账号 ID 下拉 | 业务视角直接进入，未先访问资源接入 | 展开「云账号 ID」 | 有可选项（按需请求），无需先逛资源接入 | 无 |
| P0-05 | 业务视角 GCP 防火墙条件 | 清空站点数据；业务视角 | 切到 GCP 防火墙 tab，展开综合查询 | 条件为：防火墙 ID、名称、云账号 ID；**无**云厂商 | 无 |
| P0-06 | 业务视角参数模板条件 | 清空站点数据；业务视角 | 切到参数模板 tab，展开综合查询 | 条件为：模板 ID、名称、云厂商、云账号 ID | 无 |
| P0-07 | 资源接入安全组仍有业务类条件 | 资源接入「全部云厂商」安全组列表 | 展开综合查询 | 含使用业务、管理业务，以及名称等与实现对齐的项 | 无 |
