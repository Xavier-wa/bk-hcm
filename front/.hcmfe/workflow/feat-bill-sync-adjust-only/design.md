# 只同步调账策略的场景 - 前端增加同步调账入口

## 设计目标

在账单汇总页通过「账单同步」弹窗，为用户提供两种同步范围的选择：

1. **全量同步**：保持现有逻辑，同步云厂商的全部账单数据。
2. **仅同步调账数据**：仅同步调账策略产生的金额调整数据，便于用户在期末或异常场景下快速修正账单。

新增「仅同步调账数据」模式时，弹窗中隐藏全量同步的账单内容预览，改为展示调账总金额（人民币、美金），并保留确认与二次校验流程。

---

## 入口与触发

- **触发位置**：账单汇总页顶部操作区「同步」按钮。
- **触发方式**：点击按钮后弹出 `账单同步` 对话框。
- **对话框尺寸**：宽度 800px，标题居中，底部操作栏右对齐。

---

## 弹窗布局

弹窗自上而下分为以下区域：

### 1. 顶部提示

- 使用警告色 Alert，固定提示文案：
  > 同步功能会同步对应云厂商的账单数据，数据量较大可能需要较长时间，请耐心等待。
- 位置紧贴标题下方，与下方内容保持 16px 间距。

### 2. 云厂商选择

- 使用单选样式的厂商选择组，横向排列。
- 可选厂商：腾讯云、百度云、华为云、AWS、Zenlayer。
- 默认选中当前页面已选中的云厂商；若页面未指定，默认选中第一项（腾讯云）。
- 切换厂商后，下方同步范围、内容预览应跟随刷新。

### 3. 同步范围

- 使用 Radio 单选组（圆点样式），横向排列，选项间距 24px。
- 选项：
  - **全量同步**（默认选中）
  - **仅同步调账数据**
- 选中「仅同步调账数据」时：
  - 隐藏第 4 区域「同步内容」。
  - 显示第 5 区域「调账数据」。

### 4. 同步内容（仅全量同步时展示）

- 标题：同步内容
- 列表展示当前云厂商待同步的账单条目，包含：
  - 账号
  - 待同步条数
  - 待同步金额（美金）
  - 待同步金额（人民币）
- 列表为空时显示空状态文案「暂无待同步数据」。
- 内容区最大高度限制，超出时出现纵向滚动条。

### 5. 同步内容 - 仅同步调账数据时展示

- 标题：同步内容（与全量同步模式统一）
- 展示四行汇总信息：
  - 调账金额（人民币+美金）
  - 调账金额（人民币）
  - 调账金额（美金）
  - 调账记录数量
- 金额标题列固定宽度、右对齐、禁止换行；金额数值列左对齐、加粗、橙色。
- 金额为空或 0 时显示「—」。

### 6. 二次确认

- 使用 Checkbox，文案：
  > 已确认同步以上内容，同步过程中不要进行其他操作。
- 未勾选时，「开始同步」按钮禁用。

### 7. 底部操作栏

- 左侧：取消按钮，点击关闭弹窗。
- 右侧：开始同步按钮，主色强调。
- 按钮顺序从左到右：取消、开始同步。

## 交互状态

### 默认状态

- 打开弹窗时默认选中「全量同步」。
- 云厂商默认与页面当前选择保持一致。
- 「开始同步」按钮默认禁用，需勾选确认复选框后启用。

### 切换同步范围

- 从「全量同步」切换到「仅同步调账数据」：
  - 隐藏同步内容列表。
  - 展示调账数据汇总。
  - 保留当前云厂商选择。
  - 重置确认复选框为未勾选状态。
- 从「仅同步调账数据」切换回「全量同步」：
  - 隐藏调账数据汇总。
  - 展示同步内容列表。
  - 重置确认复选框为未勾选状态。

### 切换云厂商

- 切换后重新请求对应厂商的同步预览数据（全量内容或调账汇总）。
- 请求过程中内容区显示 Loading 占位。
- 请求完成后更新列表或汇总金额。
- 重置确认复选框为未勾选状态。

### 提交同步

- 点击「开始同步」后：
  - 按钮进入 Loading 状态，禁用取消与关闭。
  - 调用同步接口，参数中携带当前选中的云厂商与同步范围。
  - 接口返回成功后关闭弹窗，并在账单汇总页刷新列表或提示「同步任务已提交」。
  - 接口返回失败时保持弹窗开启，顶部 Alert 位置或内容区下方展示错误提示。

### 关闭弹窗

- 点击取消、关闭图标或蒙层均可关闭弹窗。
- 关闭后重置弹窗内部状态（厂商、同步范围、复选框）。

## 视觉规格

### 颜色

- 弹窗标题：`Text/1 强显示` #313238，16px，加粗。
- 正文文本：`Text/2 标准` #4d4f56，14px。
- 辅助说明：`Text/3 弱显示` #979ba5，12px。
- 主按钮背景：`Brand/2 主蓝` #3a84ff。
- 警告 Alert 背景：`Warn/3 橙色` 的浅色背景，图标使用 Alert 组件默认警告图标。
- 分隔线/边框：`Neutral/7 中灰 - 线条中` #eaebf0。
- 内容区背景：`Neutral/9 背景色` #f5f7fa。

### 字体

- 弹窗标题：16px，Microsoft YaHei，Bold。
- 区域标题：14px，Microsoft YaHei，Bold。
- 正文：14px，Microsoft YaHei，Regular。
- 金额标签：12px，Microsoft YaHei，Regular。
- 金额数值：14px，MicrosoftYaHei-Bold，Bold。
- 辅助信息：12px，Microsoft YaHei，Regular。

### 间距

- 弹窗内边距：24px。
- 各区域之间间距：16px。
- 单选组内部选项间距：16px。
- 内容区表格行高：40px。
- 金额标签列宽度：200px，右对齐。
- 金额标签与数值间距：8px。
- 底部操作栏与内容区间距：24px。

---

## 异常与边界状态

| 场景 | 处理方式 |
|---|---|
| 未勾选确认复选框 | 「开始同步」按钮禁用，Hover 时无提示 |
| 同步内容为空 | 显示空状态「暂无待同步数据」，仍允许勾选并提交 |
| 调账金额为 0 | 显示「—」占位 |
| 预览接口请求失败 | 内容区显示错误提示，允许重新选择厂商触发刷新 |
| 同步接口请求中 | 按钮 Loading，禁用关闭与取消 |
| 同步接口失败 | 弹窗不关闭，内容区或 Alert 区域展示错误信息 |
