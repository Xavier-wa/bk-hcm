## 背景

云账单管理「账单汇总」支持将云厂商账单同步至公司 OBS 平台。现网「账单同步」仅支持**全量同步**；业务存在「仅需把已确认调账数据再次同步」的场景，全量同步成本高、风险大。

本期在**现有「账单同步」弹窗内**增加同步范围选择（全量 / 仅同步调账数据），联动同步内容展示，并在发起同步时携带对应接口入参；**不改造操作记录及其他页面**。

## 改动范围

| 场景 | 入口路径 | 说明 |
| --- | --- | --- |
| 账单同步弹窗 | 云账单管理 → 账单汇总 → 一级账号 →「同步」 | 弹窗内：同步范围 UI、同步内容联动、执行拦截；请求增加 `sync_mode` |

> **本期只做以上两项**：  
> 1. 前端：「账单同步」弹窗内部内容调整（UI + 同步范围选择 + 内容联动 + 必要拦截）  
> 2. 接口入参：发起同步时增加同步模式参数  

> 本期**明确不做**：操作记录（含同步 TAB 范围标识/金额列）、工具栏独立按钮、账单调整页、云账单上游 / OBS 下游、确认/导入 TAB。

## 术语：金额口径

| 展示名 | 含义 |
| --- | --- |
| 人民币+美金（￥） | 国内站人民币结算 + 美金结算 × 当月汇率折算后的汇总结算金额 |
| 人民币 | 国内站人民币原币（未与美金折算部分相加） |
| 美金 | 美金原币（未折算） |
| 调账金额（人民币+美金￥） | 已确认调账：人民币原币 + 美金 × 当月汇率 |
| 调账金额（人民币） | 已确认调账人民币原币 |
| 调账金额（美金） | 已确认调账美金原币 |

**硬规则**：`人民币+美金（￥）` 已含美金折算，**不可**再与「美金」原币相加。汇率沿用页面顶部「当月汇率」。

## 用户故事

### US1: 在账单同步弹窗选择范围并发起同步

**作为** 账单运营人员  
**我想要** 在账单同步弹窗中选择「全量同步」或「仅同步调账数据」  
**以便** 在只改动调账数据时快速、安全地同步到 OBS，而不必全量推送

#### 验收标准

- [ ] **AC-001** 打开「账单同步」弹窗后，在云厂商与同步内容之间展示「同步范围」单选组；默认「全量同步」，可选「仅同步调账数据」
- [ ] **AC-002** 已选云厂商时，切换为「仅同步调账数据」→ 同步内容展示：调账金额（人民币+美金￥）、调账金额（人民币）、调账金额（美金）、调账记录条数；标签与数值正确
- [ ] **AC-003** 已选云厂商时，切换为「全量同步」→ 同步内容展示：人民币+美金（￥）、人民币、美金、业务数量；标签与数值正确
- [ ] **AC-004** 未勾选「已确认所有步骤正确…」或存在未确认一级账号账单时，不允许执行同步（按钮禁用 + 提示，沿用现网）
- [ ] **AC-005** 选择「仅同步调账数据」且无已确认调账或调账金额合计（人民币+美金￥）为 0 时，金额/条数展示 0，同步按钮禁用并提示（硬拦截）
- [ ] **AC-006** 已选云厂商、范围合法、勾选确认且账单均已确认时，点击同步成功并提示；请求携带对应同步模式（`full` / `adjustment_only`）
- [ ] **AC-007** 全量同步历史路径在本期上线后行为与展示无破坏性影响（默认全量、未改操作记录）

## 业务规则

| 编号 | 规则 |
| --- | --- |
| R-001 | 默认同步范围 = 全量同步 |
| R-002 | 仅同步调账时，由后端按调账策略处理；前端只负责选择范围并传参 |
| R-003 | 调账金额（人民币+美金￥）= 调账人民币原币 + 调账美金 × 当月汇率；调账金额（美金）仅原币 |
| R-004 | `人民币+美金（￥）` 与「美金」原币不可相加 |
| R-005 | 仅同步调账且调账金额合计为 0 → 禁止发起同步 |
| R-006 | 权限、一级账号全部确认后方可同步等前置与现网一致 |

## 交互要点（产品层）

### 账单同步弹窗（本期唯一 UI 面）

1. 提示：账单同步会将当前云厂商数据同步给公司 OBS 平台  
2. 云厂商选择  
3. **同步范围**单选（云厂商与同步内容之间）：全量同步（默认）/ 仅同步调账数据  
4. **同步内容**随范围联动（见 AC-002 / AC-003）  
5. 操作前核对说明 + 确认勾选（沿用现网）  
6. 同步 / 取消  

切换云厂商或同步范围时，同步内容标签与数值一并刷新。

### 接口入参（产品约束）

- 接口：`POST /api/v1/account/bills/sync_records`  
- 新增可选参数 `sync_mode`：  
  - `full`：全量同步（默认；缺省按 full）  
  - `adjustment_only`：只同步调账  
- 前端按弹窗所选范围映射并提交；其余入参沿用现网。
