# feat-adjustment-category 测试清单

> 工作流: `feat-adjustment-category`
> 关联文档: PRD / Design / API / Coding

## 验证范围

- 功能边界: 调账新增/编辑表单的云厂商禁用、资源类别四值、资源子类候选联动与提交归一化，以及调账列表资源子类列展示。
- 不在范围: 后端枚举/数据迁移、OBS 同步、导出文件、资源子类筛选、其他页面复用的云厂商选择行为。

## 测试环境

- 前端入口: `<账单管理-账单调整对应业务的测试环境地址，由执行人在测试时确认>`
- 测试账号: `<test_account>`
- 数据准备:
  - 准备一个可编辑的未确认调账记录，分别覆盖 `aws`、`gcp`、`huawei`；如需验证历史非适配厂商展示，准备一条 `azure` 或 `zenlayer` 的历史记录。
  - 准备候选接口返回数据：`gpu_cards` 返回至少 2 个卡型，`api_brands` 返回至少 2 个模型厂商；空数组场景可使用后端空数据或 `page.route` 拦截模拟。
  - 准备列表中资源子类有值和空字符串的调账记录。
  - 接口失败场景使用 `page.route` 返回业务错误，不依赖修改真实后端数据。

## 用例清单

### P0 - 主流程（必测）

| ID | 场景 | 前置 | 操作 | 期望 | 回滚 |
|----|------|------|------|------|------|
| P0-01 | 展示云厂商可用状态 | 打开新增调账表单 | 查看云厂商按钮组并尝试点击各厂商 | `aws`、`gcp`、`huawei` 可选；`azure`、`zenlayer` 等其余选项显示 disabled 且点击不改变当前厂商 | 关闭表单 |
| P0-02 | 新建 GPU 卡调账 | 云厂商选择 `aws` 或 `gcp`；卡型接口可返回候选 | 新增一行，选择资源类别“GPU卡”，选择一个卡型，填写其他必填项并提交 | 发起卡型候选请求；资源子类展示候选；提交请求的 `res_class` 为 `gpu_card`、`res_sub_class` 为选中卡型；创建成功并刷新列表 | 删除新建记录 |
| P0-03 | 新建 GPU API 调账 | 云厂商选择 `aws` 或 `gcp`；模型厂商接口可返回候选 | 新增一行，选择资源类别“GPU API”，选择一个模型厂商，填写其他必填项并提交 | 发起模型厂商候选请求；资源子类展示候选；提交请求的 `res_class` 为 `gpu_api`、`res_sub_class` 为选中模型厂商；创建成功并刷新列表 | 删除新建记录 |
| P0-04 | 新建 CPU 或 GPU 其他调账 | 已打开新增表单 | 分别选择“CPU”和“GPU其他”，填写其他必填项并提交 | 资源子类无候选；请求体始终包含 `res_sub_class: ""`；创建成功 | 删除新建记录 |
| P0-05 | 展示列表资源子类 | 列表存在资源子类有值和空值的记录 | 打开/刷新调账列表 | “资源子类”列紧跟“资源类别”列；有值时展示原值，空值展示 `--` | 无 |

### P1 - 异常分支（必测）

| ID | 场景 | 前置 | 操作 | 期望 |
|----|------|------|------|------|
| P1-01 | 非适配厂商不请求候选接口 | 新增表单中存在被 disabled 的厂商选项；可用历史数据可用于编辑态展示 | 尝试点击非适配厂商；如通过历史记录进入编辑态，观察资源子类区域 | disabled 厂商不能被新建表单选中；不发起 `gpu_cards` / `api_brands` 请求；已有非适配厂商记录的当前厂商仍正常展示 |
| P1-02 | 候选接口空数据 | 当前厂商为支持厂商；候选接口返回 `[]` | 选择“GPU卡”或“GPU API” | 资源子类下拉为空，不展示虚构选项；页面不因空数据崩溃 |
| P1-03 | 候选接口失败 | 使用 `page.route` 让候选接口返回业务错误 | 选择对应资源类别触发请求 | 沿用现有错误提示；候选列表为空；不会把错误响应写入选项 |
| P1-04 | 类别切换清空子类 | 已选择 GPU 卡型或模型厂商 | 将资源类别切换为 CPU 或 GPU其他，再提交 | 资源子类值立即清空；请求体不带切换前的旧值，并显式提交空字符串 |
| P1-05 | 云厂商切换清空子类 | 已选择 `aws`/`gcp` 的 GPU 卡型或模型厂商 | 切换到另一个可用云厂商 | 所有调账行资源子类清空；按新厂商和当前类别重新请求候选；旧请求结果不会覆盖新厂商候选 |
| P1-06 | 编辑回填资源子类 | 存在未确认的 GPU 卡/API 调账记录 | 点击编辑打开表单 | 资源类别、资源子类按接口数据回填；候选列表按当前云厂商和类别加载；提交未改动数据时资源子类仍为字符串 |
