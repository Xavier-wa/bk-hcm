### 稿面识别结论

- 参考图为调账新增/编辑表单中的云厂商选择区域，位于表单顶部、一级账号之前。
- 云厂商以横向带 Logo 的按钮组展示，沿用现有页面的卡片式/按钮式选择形态。
- 当前按钮顺序沿用现有实现：微软云、谷歌云、华为云、亚马逊云、zenlayer。
- 本次状态规则覆盖参考图中的云厂商选项：`aws`、`gcp`、`huawei` 保持可用；`azure`、`zenlayer` 等其余厂商显示 disabled。

## 2. 信息架构 / 布局

### 新增/编辑调账表单

沿用现有 `CommonSideslider` 与垂直表单结构，不调整页面层级：

1. 云厂商（必填）
   - 横向云厂商按钮组。
   - `aws`、`gcp`、`huawei` 为可用项。
   - 非适配云厂商保留原有 Logo 与文案，但按钮置为 disabled。
2. 一级账号（必填）
   - 沿用现有账号选择组件。
   - 云厂商切换后按现有行为清空并重新加载账号候选。
3. 币种（必填）
   - 沿用现有选择器。
4. 调账配置（必填）
   - 现有列顺序中，在“资源类别”后插入“资源子类”。
   - 资源子类位于资源类别列与金额列之间。
5. 结果预览与提交区
   - 沿用现有金额预览、提交、取消布局。

### 调账列表

- 在“资源类别”列后增加“资源子类”列。
- 有值时直接展示接口返回字符串；空值展示 `--`。
- 不增加资源子类筛选入口，不改变现有列表操作区。

## 3. 关键交互

### 3.1 云厂商选项

| 选项 | 值 | 新增态 | 编辑态 |
|------|----|--------|--------|
| 亚马逊云 | `aws` | 可选择 | 跟随现有编辑态整体禁用规则 |
| 谷歌云 | `gcp` | 可选择 | 跟随现有编辑态整体禁用规则 |
| 华为云 | `huawei` | 可选择 | 跟随现有编辑态整体禁用规则 |
| 微软云 | `azure` | disabled，不可选择 | 已有数据仍正常展示，跟随现有编辑态整体禁用规则 |
| zenlayer | `zenlayer` | disabled，不可选择 | 已有数据仍正常展示，跟随现有编辑态整体禁用规则 |

- disabled 只限制用户在新增态选择未适配厂商，不删除选项、不隐藏 Logo、不改变选项顺序。
- 编辑已有非适配厂商数据时，当前云厂商值仍需展示；不可通过表单切换厂商。
- 新增态用户点击可用厂商后，沿用现有行为清空一级账号，并触发依赖云厂商的数据刷新。

### 3.2 资源类别与资源子类

- 资源类别始终展示四个选项：CPU、GPU卡、GPU API、GPU其他。
- 资源类别为 GPU卡：资源子类使用卡型候选。
- 资源类别为 GPU API：资源子类使用模型厂商候选。
- 资源类别为 CPU 或 GPU其他：资源子类无候选，保持空值。
- 仅 `aws`、`gcp`、`huawei` 允许请求资源子类候选接口；其他厂商不请求接口，资源子类下拉为空。
- 切换资源类别或云厂商后，清空不再适用的资源子类值；提交时资源子类始终传字符串，缺省传空字符串。
- 资源子类为非必填字段，不展示必填星号，不阻止用户提交空值。

### 3.3 列表展示

- 资源子类列紧邻资源类别列之后。
- 空值使用 `--`，不使用空白造成列内容缺失。
- 长文本沿用现有表格溢出处理，不新增详情浮层。

### 3.4 交互状态

| 状态 | 设计行为 |
|------|----------|
| 初始 | 新增行资源类别默认 CPU；云厂商按现有默认值与可用态规则展示 |
| 选中 | 可用云厂商保持现有选中态；资源类别和资源子类按当前行值展示 |
| disabled | 未适配云厂商按钮保留在组内，使用组件原生 disabled 视觉与交互，不响应点击 |
| 加载 | 资源子类候选请求期间沿用现有选择器 loading 状态，不允许误提交未完成的选择更新 |
| 空数据 | 接口返回空数组或厂商不支持请求时，资源子类下拉无选项；字段保持空字符串 |
| 请求失败 | 沿用现有接口错误处理和选择器异常态，不新增独立页面级错误布局 |
| 提交成功 | 沿用现有成功提示并关闭表单/刷新列表 |
| 取消 | 沿用现有取消行为，不保存当前编辑内容 |

## 4. 状态流转

```text
新增表单打开
  → 云厂商选项按适配白名单渲染
  → 用户选择 aws/gcp/huawei
  → 一级账号按厂商刷新
  → 调账行默认资源类别 CPU
  → 用户选择资源类别
      ├─ CPU/GPU其他 → 资源子类无候选，值为空字符串
      ├─ GPU卡 → 支持厂商请求卡型接口 → 展示返回候选或空列表
      └─ GPU API → 支持厂商请求模型厂商接口 → 展示返回候选或空列表
  → 用户切换类别/厂商 → 清空失效资源子类
  → 提交 → 资源子类字段始终为字符串
  → 成功 → 关闭表单并刷新列表
```

编辑态：

- 云厂商沿用现有整体 disabled 行为；已有非适配厂商值仅展示，不提供切换入口。
- 资源类别与资源子类按接口返回值回填；不适用值按提交规则归一为空字符串。

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 非适配厂商新增 | 选项保留，按钮 disabled，点击无响应 |
| 非适配厂商历史数据编辑 | 当前厂商名称与 Logo 正常展示，整体不可切换 |
| 支持厂商候选接口返回空数组 | 资源子类选择器为空，不展示虚构候选值 |
| 非适配厂商资源类别为 GPU卡/GPU API | 不请求候选接口，资源子类为空，提交空字符串 |
| 资源类别切换 | 清空不适用的旧资源子类，防止隐藏字段提交 |
| 顶层云厂商切换 | 清空所有调账行资源子类，并刷新相关候选 |
| 候选接口加载中 | 资源子类选择器展示现有 loading 状态 |
| 候选接口失败 | 沿用现有请求错误反馈；不将错误响应当作候选项 |
| 资源子类为空的列表数据 | 列展示 `--` |
| 选项文案较长 | 沿用现有按钮组宽度与页面溢出策略，不新增换行规则 |
