## 验证范围

- 功能边界: chatbot 指令模板模式 · 主机申领相关 CUSTOM 模板的下行渲染、交互回传、只读/历史回放。本迭代落地四类模板：
  - **A 申领方案推荐**（`after_tool_hitl.recommend_select.interrupt`）：键值表 + 多条翻页 + 来源标签 + 选择方案/添加到配置清单。
  - **B 预提单数据**（`after_tool_hitl.recommend_suborder_confirm.interrupt`）：配置表格 + 行内编辑 + 全屏 + 确认方案/添加到配置清单。
  - **C 调整配置弹窗**：由 B 行内编辑触发的左侧表单（含校验），保存写回行。
  - **D 确认提交申请单**（`tool_confirm.interrupt.create_cvm_apply`）：**只读**表格（含系统盘/数据盘列、无操作列）+ 全屏 + 确认提交/添加到配置清单。
- 不在范围:
  - agent 侧模板配置/下发逻辑（后端负责，前端只消费）。
  - 「添加到配置清单」回填配置清单的数据契约（本迭代仅跳转 + 预留入口，留后续「回填」需求）。
  - 上行 resume 承载形式的端到端正确性（前端按隔离假设实现，待后端确认，见 api.md §6）；本清单只验证前端**发出的请求体结构**符合约定。
  - jsonschema 模式的云账号选择卡（属上一迭代）。

  - **备用构造**：若 agent 链路不便复现，可用 api.md §3/§4/§4.5 的真实 SSE 样例，按 `CUSTOM` 事件名注入 eventstream 验证单卡渲染。

## 用例清单

### P0 - 主流程（必测）

| ID | 场景 | 前置 | 操作 | 期望 | 回滚 |
|----|------|------|------|------|------|
| P0-01 | A 推荐方案卡渲染 + 翻页 + 来源标签 | 收到 A 事件（多条 recommendations） | 查看卡片，点击「上一个/下一个」翻页 | 渲染键值表（按后端编码原样展示字段）；分页标识 `当前/总数` 同步；首/尾条对应翻页按钮置灰；每条展示来源标签（`user`=用户历史配置 / `biz`=业务推荐） | — |
| P0-02 | A 选择方案回传并触发 B | A 卡可交互 | 选中某条方案 → 点击「选择方案」 | 请求体 `forwardedProps.resumeValue` = `帮我基于此方案进行拆单` + 选中 suborder 的 JSON 串；用户气泡「我选择该申领方案」；A 卡转只读；agent 随后返回 B 卡 | — |
| P0-03 | B 预提单表格 + 行内编辑写回 | 收到 B 事件 | 查看表格列（机型/操作系统/申请数量/地域/可用区/计费模式/需求类型）→ 点击行尾编辑 icon → C 弹窗改某字段 → 保存修改 | 表格按 suborders 渲染；编辑弹窗回填该行；保存后该行数据更新 | 重新拉起对话 |
| P0-04 | B 确认方案回传并触发 D | B 卡可交互（可含 C 修改） | 点击「确认方案」 | 请求体 `forwardedProps.resumeValue` = 完整 suborders 数组 JSON 串（含 C 修改）；B 卡转只读；agent 返回 D 卡 | — |
| P0-05 | D 确认提交卡渲染（只读、无操作列） | 收到 D 事件 | 查看 D 卡表格与按钮 | 表格只读、**无操作列**；列含系统盘/数据盘；横幅「已确认 N 条申领配置方案，可点击按钮提交申请单」；底部按钮固定为「确认提交」(主) + 「添加到配置清单」，**无取消** | — |
| P0-06 | D 确认提交回传整个 data | D 卡可交互 | 点击「确认提交」 | 请求体 `forwardedProps.resumeValue` = D 的整个 `data` 对象（含 `body_param` 与 `path_param` 两个 key）的 JSON 串；用户气泡「确认提交」；D 卡转只读 | — |
| P0-07 | 提交后只读态收起/展开 | A/B/D 任一已提交 | 查看已提交卡 → 点击摘要行展开/收起 | 默认收起为摘要行（绿对勾 + 摘要文案）；D 只读摘要文案为「请确认全部方案信息，并提交申请单」；可展开预览只读内容，展开态下所有按钮置灰不可交互 | — |

### P1 - 异常分支 / 边界（必测）

| ID | 场景 | 前置 | 操作 | 期望 |
|----|------|------|------|------|
| P1-01 | C 调整弹窗必填校验 | B 行内编辑打开 C 弹窗 | 清空「申请数量/地域/机型」任一必填项 → 点击保存修改 | 表单红字校验提示，**不写回**、不关闭弹窗；计费模式字段只读不可编辑 |
| P1-02 | 约定外 CUSTOM 事件保持原生输出 | agent 返回 `name` 不在约定集合的 CUSTOM 事件 | 观察对话流 | **不渲染**任何主机申领卡、不报错；该事件按原生文本气泡（伴随的 TEXT_MESSAGE）展示 |
| P1-03 | D 可用区 zones 数组展示 | D 卡 `spec.zones=["all"]`（无 `zone`） | 查看 D 表格「可用区」列 | 正确展示 `all`（数组 join），**不显示** `--` |
| P1-04 | 添加到配置清单跳转一致 | A / B / D 任一卡可交互 | 分别点击各卡「添加到配置清单」 | 三处均通过 `routerAction` 跳转主机申请页面（`MENU_SERVICE_HOST_APPLICATION`），不直接用 vue-router；不发起 resume 回传 |
| P1-05 | 历史回放还原只读 | 已完成 A/B/D 提交的会话 | 刷新页面 / 重新进入该历史会话 | A/B/D 卡还原为只读态，内容与当时一致（A 退化展示已选下标方案、B/D 展示提交时数据）；无报错 |
