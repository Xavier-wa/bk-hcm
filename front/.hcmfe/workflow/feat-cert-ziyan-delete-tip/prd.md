# PRD — 自研云证书-云上不支持删除，页面需提示

- **关联需求**: 1069995598137236186「证书管理-删除证书前检查证书的绑定关系」（后端删除前校验绑定关系，与本需求相互独立）

## 1. 背景与问题

HCM 证书管理提供证书的上传、查看、分配业务与删除能力。删除操作由 HCM 前端发起，最终调用云上 SSL 证书服务的删除接口。

**当前问题**：自研云的云上证书服务**不支持删除证书**。用户在证书列表对自研云证书点击「删除」时，请求必然失败（云上返回未授权/不支持的报错），但：

- 用户无法在点击前从界面预知该操作不可行；
- 用户容易把失败理解为系统故障或自身权限问题，进而反复重试或提单咨询。

**不做的影响**：自研云证书的删除入口看起来可用，将持续产生必然失败的云上请求，带来无谓的失败单据与咨询成本。

## 2. 用户故事

| 角色 | 用户故事 |
| --- | --- |
| HCM 使用者（业务运维） | 作为 HCM 使用者，我希望在证书列表看到自研云证书时，删除按钮已经是置灰的，以便不用点下去才发现删不掉 |
| HCM 使用者（业务运维） | 作为 HCM 使用者，我希望悬停置灰的删除按钮时看到「自研云证书不允许删除，如有疑问，请联系C2000」的提示，以便清楚这是平台能力限制，而不是系统故障或我的权限问题 |
| 平台运维 | 作为平台运维，我希望自研云证书的删除入口被明确禁用并给出原因，以便减少因「删不掉」产生的重复操作与咨询工单 |

## 3. 功能需求

### 3.1 功能点清单

| 编号 | 功能描述 | 优先级 | 涉及角色 | 备注 |
| --- | --- | --- | --- | --- |
| F-001 | 自研云证书的删除按钮置灰，不可点击 | P0 | HCM 使用者 | 必须 |
| F-002 | 置灰的删除按钮悬停时提示「自研云证书不允许删除，如有疑问，请联系C2000」 | P0 | HCM 使用者 | 必须 |

### 3.2 [F-001] 自研云证书删除按钮置灰

- **输入**：证书列表每一行证书数据（含该证书所属云厂商）。
- **处理逻辑**：
  1. 渲染操作列的「删除」按钮时，读取当前行证书所属的云厂商；
  2. 若云厂商为自研云，则该按钮置灰且不可点击，**不触发删除确认弹窗、不发起删除请求**；
  3. 其余云厂商的证书维持原有删除能力不变。
- **输出**：自研云证书行的删除按钮为禁用态。
- **边界条件**：
  - 业务视角与资源视角**均生效**，判定只看证书自身所属云厂商，与当前所处视角无关；
  - 已分配业务的证书在资源视角下原本就置灰（提示「该证书已分配业务, 仅可在业务下操作」）；自研云证书在两种情况下都置灰，具体提示内容见规则 R-003；
  - 无删除权限的用户看到自研云证书时，按钮同样是置灰态（权限禁用行为不变）。

### 3.3 [F-002] 置灰删除按钮的 tips 提示

- **输入**：用户对置灰删除按钮的鼠标悬停动作。
- **处理逻辑**：沿用列表已有的 tooltip 机制，在按钮的提示载体上挂载文案「自研云证书不允许删除，如有疑问，请联系C2000」。
- **输出**：悬停后展示包含「自研云证书不允许删除，如有疑问，请联系C2000」的提示气泡。
- **边界条件**：
  - 按钮可点击（非自研云且无其它禁用原因）时不展示该提示；
  - 提示文案固定为「自研云证书不允许删除，如有疑问，请联系C2000」，不做动态拼接、不加标点扩展。

## 4. 业务规则

| 编号 | 规则 | 说明 |
| --- | --- | --- |
| R-001 | **判定依据** | 以证书数据自身的云厂商字段为准，与列表「云厂商」列展示保持同一数据源；自研云的取值为 `tcloud-ziyan`。不使用账号的云厂商做判定 |
| R-002 | **禁用范围** | 仅禁用列表操作列的单条删除按钮，不影响证书上传、分配业务、批量分配业务等其它操作 |
| R-003 | **提示优先级** | 自研云是比「已分配业务」更前置、更根本的不可用原因。自研云证书无论是否已分配业务，提示统一为「自研云证书不允许删除，如有疑问，请联系C2000」 |
| R-004 | **不阻断其它能力** | 本需求不做批量删除、不做删除前的绑定关系校验，也不改动删除接口本身 |
| R-005 | **字段缺失兜底** | 云厂商字段缺失时按「非自研云」处理，保持原有可删除行为，不误伤存量数据 |

## 5. 非功能需求

- **性能**：本需求为纯渲染层判定，不引入额外请求，列表渲染耗时无变化。
- **安全 / 权限**：沿用现有证书删除权限模型。本需求不新增、不放宽任何权限点；无权限用户的按钮置灰行为保持不变。
- **兼容性**：
  - **厂商兼容**：仅自研云受限；腾讯云、AWS、Azure、GCP、华为云、Zenlayer、靠谱云、其他云厂商行为完全不变；
  - **视角兼容**：业务视角（证书托管）与资源视角（资源管理-证书）均一致生效。

## 6. 验收标准

### 6.1 功能验收

- [ ] **AC-001**：Given 证书列表中存在一条自研云证书，When 页面渲染该行操作列，Then 「删除」按钮为置灰状态且点击无响应（不弹确认框、不发请求）。
- [ ] **AC-002**：Given 用户将鼠标悬停在自研云证书行置灰的删除按钮上，When 悬停持续至提示出现，Then 提示气泡文案为「自研云证书不允许删除，如有疑问，请联系C2000」。
- [ ] **AC-003**：Given 一条腾讯云证书，且用户有删除权限、资源视角下未分配业务，When 渲染该行操作列，Then 删除按钮可点击，且不展示「自研云证书不允许删除，如有疑问，请联系C2000」提示。
- [ ] **AC-004**：Given 同一张自研云证书分别在业务视角与资源视角查看，When 渲染操作列，Then 两个视角下删除按钮均置灰，且提示文案一致为「自研云证书不允许删除，如有疑问，请联系C2000」。
- [ ] **AC-005**：Given 资源视角下一张自研云证书同时处于已分配业务状态，When 悬停其删除按钮，Then 提示为「自研云证书不允许删除，如有疑问，请联系C2000」，而非「该证书已分配业务, 仅可在业务下操作」。
- [ ] **AC-006**：Given 用户无证书删除权限，When 查看自研云证书行，Then 删除按钮为置灰态，权限禁用行为与之前一致。
- [ ] **AC-007**：Given 自研云证书所在行，When 查看批量分配业务功能，Then 批量分配业务等其它操作不受本需求影响，行为不变。

### 6.2 性能与安全验收

- [ ] **AC-P01**：Given 证书列表包含自研云与非自研云证书各若干条，When 列表完成渲染，Then 渲染耗时与改动前无明显差异，不产生额外请求。
- [ ] **AC-S01**：Given 用户无证书删除权限，When 尝试点击自研云证书的删除按钮，Then 按钮不可点击，不产生任何删除请求。

## 7. 边界范围

### 7.1 本期包含

- 证书列表操作列删除按钮按云厂商（自研云）禁用；
- 自研云证书置灰删除按钮的「自研云证书不允许删除，如有疑问，请联系C2000」tips 提示；
- 业务视角与资源视角同时生效。

### 7.2 本期不包含

- 云上 / 后端自研云删除证书能力的支持；
- 批量删除证书能力（当前产品无此入口）；
- 删除前的证书绑定关系校验（由关联需求 1069995598137236186 承载）；
- 证书上传、分配业务等其它操作的厂商限制；
- 证书详情页（当前产品无此页面）。

## 8. 约束条件

- **数据约束**：判定完全依赖列表接口已返回的云厂商字段，不新增接口、不新增数据字段。
- **范围约束**：改动限定在证书列表操作列的删除按钮渲染逻辑内，不改动删除接口与删除确认流程本身。
- **兼容约束**：非自研云厂商的删除行为必须保持与改动前完全一致。
