## 2. 信息架构 / 布局

### 2.1 页面整体框架

```
┌─────────────────────────────────────────────────────────────┐
│  机房裁撤                              [同步] [裁撤配置]     │
├─────────────────────────────────────────────────────────────┤

├─────────────────────────────────────────────────────────────┤
│  搜索栏（两行平铺，GridContainer + GridItemFormElement）       │
│  Row1: 裁撤时间 | 项目类型 | ...                             │
│  Row2: 地域 | 可用区 | ... | [查询] [重置]                   │
├─────────────────────────────────────────────────────────────┤
│                                                             │
│  表格区域（总览 or 明细，随 Tab 切换）                         │
│                                                             │
└─────────────────────────────────────────────────────────────┘
```

**布局要点**：
- 页面标题「机房裁撤」位于页面内容区顶部
- 右上角操作区：两个 outline 按钮「同步」和「裁撤配置」，需 `AUTH_UPDATE_DISSOLVE` 权限控制
- Tab 栏紧跟标题下方，激活 Tab 为蓝色底白字，未激活为灰色文字
- 每个 Tab 各自拥有独立的搜索栏和表格区域
- 搜索栏使用 GridContainer 平铺布局，不使用折叠/高级筛选

### 2.6 裁撤时间段选择器（定制组件）

> **无设计稿**。用户确认使用项目 bkui 组件库实现。以下基于 PRD F-007 功能描述定义行为规范。

**组件定位**：搜索栏中「裁撤时间」条件的定制多选选择器，供总览/明细两个 Tab 共享使用。

**交互规范**：

| 属性 | 值 |
|------|-----|
| 触发方式 | 点击输入框展开下拉面板 |
| 面板内容 | 从接口获取的时间段选项列表 |
| 选项格式 | 「开始日期 至 结束日期 (当前)」—— 带"(当前)"后缀的为默认选中项 |
| 选择模式 | 多选 + 全选 |
| 面板底部 | 显示"已选择 N 项" + [取消] [确定] 按钮 |
| 回填形态 | 选中的每个时间段以 tag 标签形式展示在输入框内，tag 文本格式为「YYYY-MM-DD~YYYY-MM-DD」 |
| 默认选中 | 页面加载时，自动选中裁撤配置中 `is_current=true` 的时间段（多个则全选） |

**技术建议**：优先考虑 `bk-tag-input` 或 `bk-popover` + 自定义面板组合实现。

## 3. 关键交互

### 3.1 Tab 切换

| 场景 | 行为 |
|------|------|
| 直接点击「裁撤明细」Tab | 切换 Tab，保持各自上次的搜索条件和分页状态，不重置 |
| 直接点击「裁撤总览」Tab | 切换 Tab，保持各自上次的搜索条件和分页状态，不重置 |
| 从总览点击某行业务名称 | 自动切换到「裁撤明细」Tab，覆盖明细的裁撤时间段/项目类型/业务名称三个字段，自动触发查询 |

### 3.2 总览 → 明细联动跳转

| 步骤 | 行为 | 数据传递 |
|------|------|---------|
| 1 | 用户点击总览表中某行的业务名称链接 | — |
| 2 | 提取当前总览的：裁撤时间段、项目类型 + 被点击行的业务名称 | 三个字段写入共享 composable |
| 3 | 自动切换到「裁撤明细」Tab | — |
| 4 | 明细 Tab 检测到携带条件，自动触发查询 | — |
| 边界 | 汇总行（bk_biz_id="total"）的业务名称不可点击，不做链接样式 | — |

### 3.3 搜索栏交互

| 操作 | 行为 |
|------|------|
| 点击「查询」 | 按当前搜索条件请求表格数据，重置分页到第 1 页 |
| 点击「重置」 | 清空本 Tab 所有搜索条件为初始值，并自动触发查询 |
| 联动（可用区 ↔ 地域） | 选择地域后联动更新可用区选项；选择可用区后联动更新机房园区选项 |

### 3.4 批量复制

| 步骤 | 行为 |
|------|------|
| 1 | 用户在明细表格勾选 ≥1 行 | 「批量复制」按钮解除禁用 |
| 2 | 点击「批量复制 ▾」 | 展开下拉菜单，两个选项：「内网IP」「固资号」 |
| 3 | 选择「内网IP」 | 收集选中行的 inner_ip 字段（空值跳过），用换行符拼接，写入剪贴板，toast 提示「已复制 N 条」 |
| 4 | 选择「固资号」 | 同理收集 asset_id 字段 |

### 3.5 同步弹窗

| 步骤 | 行为 |
|------|------|
| 1 | 点击「同步」按钮 | 弹出同步弹窗，从 `getDissolveConfig` 接口获取项目类型列表渲染（只读） |
| 2 | 弹窗展示 | 项目类型以 checkbox 形式展示（视觉上为已勾选态，但不响应点击切换） |
| 3 | 点击「确定」 | 调用同步接口，按钮 loading，禁止重复点击 |
| 3a | 成功 | 关闭弹窗，toast「同步成功」，刷新当前 Tab 表格数据 |
| 3b | 失败 | toast 错误信息，弹窗保持打开 |
| 4 | 点击「取消」或 × | 关闭弹窗，不做任何操作 |

### 3.6 裁撤配置弹窗

| 步骤 | 行为 |
|------|------|
| 1 | 点击「裁撤配置」按钮 | 弹出弹窗，调用 `getDissolveConfig` 获取当前配置回填表单 |
| 2 | 编辑配置 | 可修改基础参数、新增/删除时间段块、修改已有时间段 |
| 3 | 点击「确定」 | 前端校验（必填/数值范围/时间重叠），通过后调用 `upsertDissolveConfig` |
| 3a | 成功 | toast「保存成功」，关闭弹窗，刷新时间段选择器选项 |
| 3b | 校验失败 | 对应字段展示错误提示，弹窗不关闭 |
| 3c | 接口失败 | toast 错误信息，弹窗不关闭 |
| 4 | 点击「取消」或 × | 关闭弹窗，丢弃未保存修改 |

## 4. 状态流转

### 4.1 页面加载流程

```
页面进入
  ├── 加载裁撤配置 (getDissolveConfig)
  │   ├── 成功 → 初始化时间段选择器选项 + 默认选中 is_current 项
  │   └── 失败 → 时间段选择器展示空，提示"时间段数据加载失败"
  ├── 初始化总览 Tab 搜索栏（含默认选中的时间段）
  ├── 自动触发总览查询
  └── 渲染总览表格
```

### 4.2 Tab 切换状态机

```
[总览Tab] ──直接点击明细Tab──→ [明细Tab]（保持明细上次状态）
[总览Tab] ──点击业务名称链接──→ [明细Tab]（携带条件，自动查询）
[明细Tab] ──直接点击总览Tab──→ [总览Tab]（保持总览上次状态）
```

### 4.3 同步弹窗状态

```
[关闭] ──点击"同步"按钮──→ [打开: 展示项目类型列表]
                                │
                   ┌────────────┼────────────┐
                   │            │            │
             点击"确定"     点击"取消"     点击"×"
                   │            │            │
              [loading...]   [关闭]        [关闭]
                │    │
           成功 │    │ 失败
                ▼    ▼
          [关闭+刷新] [保持打开+错误提示]
```

### 4.4 裁撤配置弹窗状态

```
[关闭] ──点击"裁撤配置"──→ [打开: 回填配置]
                              │
                 ┌────────────┼────────────┐
                 │            │            │
           点击"确定"     点击"取消"     点击"×"
           (前端校验)         │            │
                 │            │            │
          通过 │    │ 不通过   │            │
                ▼    ▼         │            │
        [保存中...] [字段报错] [关闭]       [关闭]
           │    │
      成功 │    │ 失败
           ▼    ▼
     [关闭+刷新] [保持打开+错误提示]
```

## 5. 异常 / 边界态

| 场景 | 展示 |
|------|------|
| 表格无数据 | bk-table 内置 empty 状态，提示「暂无数据」 |
| 查询接口超时 (>3s) | 表格区域展示 loading，超时后 toast「查询超时，请重试」 |
| 查询接口报错 | 表格区域展示错误提示（bk-table 内置 error state 或自定义 error slot） |
| 搜索条件下拉选项加载失败 | 该下拉展示空选项，placeholder 保持不变 |
| 同步弹窗 - 配置接口失败 | 弹窗内展示空列表，toast「配置加载失败」 |
| 同步操作超时 (>30s) | toast「同步超时，请稍后查看结果」 |
| 同步操作失败 | toast 具体错误信息，弹窗保持打开 |
| 裁撤配置 - 获取失败 | 弹窗展示空配置（各字段为空/默认值） |
| 裁撤配置 - 保存失败 | toast 错误信息，弹窗不关闭 |
| 裁撤配置 - 时间重叠校验失败 | 对应时间段块的日期选择器下方展示红色提示「时间范围不允许重叠」 |
| 裁撤配置 - 数值超出范围 | 对应输入框下方展示红色范围提示 |
| 批量复制 - 浏览器不支持 clipboard API | toast「复制失败，请手动复制」 |
| 导出失败 | toast「导出失败，请重试」 |
| 无 AUTH_UPDATE_DISSOLVE 权限 | 「同步」和「裁撤配置」按钮不渲染（hcm-auth noPerm 时隐藏） |
| 时间段选择器 - 选项接口失败 | 选择器展示空面板，toast「时间段数据加载失败」 |
