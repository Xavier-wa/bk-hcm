## ADDED Requirements

### Requirement: 邮件标题与收件人配置化
系统 SHALL 以配置化收件人列表发送周报，邮件标题格式为 `IEG-销毁返还预测统计周报-{{发送日（周一当天日期）}}`。

#### Scenario: 从配置读取收件人
- **GIVEN** 配置中定义收件人列表
- **WHEN** 系统发送邮件
- **THEN** 收件人为配置中的列表（默认空列表，由部署环境在 yaml / helm 中配置）
- **AND** 运维可通过调整配置动态修改收件人，无需改代码重新部署

#### Scenario: 标题日期为发送日
- **GIVEN** 触发日为周一（如 2026-01-12）
- **WHEN** 系统组装邮件标题
- **THEN** 标题为 `IEG-销毁返还预测统计周报-2026-01-12`

### Requirement: 有单据邮件正文
系统 SHALL 在命中记录时发送含汇总头与明细表的 HTML 邮件，并附疑问联系人备注。

#### Scenario: 有单据样式
- **GIVEN** 统计周期内命中记录
- **WHEN** 系统组装并发送邮件
- **THEN** 正文含标题、汇总头、转移免审单详情明细表
- **AND** 备注含疑问联系人 / ICR(IEG资源服务助手)
- **AND** 经 cmsi 邮件网关以 HTML 富文本发送，样式对齐现有 HCM 通知邮件

### Requirement: 无单据邮件正文
系统 SHALL 在命中 0 条时发送简化邮件，不跳过发送。

#### Scenario: 无单据样式
- **GIVEN** 统计周期内命中 0 条
- **WHEN** 系统发送邮件
- **THEN** 邮件照常发送
- **AND** 正文为"本统计周期内，无资源预测转移免审单"
- **AND** 不渲染空表

### Requirement: 邮件仅发送内部收件人
系统 SHALL 仅将邮件发送给固定内部收件人，不对外暴露。

#### Scenario: 收件人不对外暴露
- **GIVEN** 周报邮件生成
- **WHEN** 系统发送邮件
- **THEN** 收件人为固定内部干系人列表
- **AND** 邮件内容（内部资源规划数据）不向外部地址发送
