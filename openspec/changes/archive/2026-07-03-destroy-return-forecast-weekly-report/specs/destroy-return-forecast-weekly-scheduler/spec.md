## ADDED Requirements

### Requirement: 销毁返还预测周报定时触发
系统 SHALL 每周一 08:00:00 触发销毁返还预测周报任务，仅由主节点（master）执行一次，并以"上周一 00:00:00 ~ 上周日 23:59:59"为统计周期。

#### Scenario: 周一到达触发时间由 master 执行
- **GIVEN** 系统到达周一 08:00:00
- **AND** 当前节点为 master 节点
- **WHEN** 定时任务触发
- **THEN** 系统以"上周一 00:00:00 ~ 上周日 23:59:59"为统计周期启动报表生成与发送流程
- **AND** 同一周期内非 master 节点不执行

#### Scenario: 非周一或非到达时间不触发
- **GIVEN** 当前日期不是周一
- **WHEN** 定时任务检查触发条件
- **THEN** 系统不触发周报任务

#### Scenario: 多节点仅 master 执行
- **GIVEN** 集群中存在多个节点
- **AND** 当前节点非 master
- **WHEN** 周一 08:00:00 到达
- **THEN** 系统不执行报表发送，避免重复发送

### Requirement: 统计周期计算
系统 SHALL 将统计周期固定计算为上次自然周的周一 00:00:00 至周日 23:59:59。

#### Scenario: 正确计算上周周期
- **GIVEN** 触发日为周一
- **WHEN** 系统计算统计周期
- **THEN** 统计开始时间 = 上周一 00:00:00
- **AND** 统计结束时间 = 上周日 23:59:59
