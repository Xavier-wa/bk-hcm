### 描述

- 该接口提供版本：v9.9.9+。
- 该接口所需权限：业务-智能体助手。
- 该接口功能描述：更新指定业务下的 AI Agent 会话名称。

### URL

PATCH /api/v1/agent/bizs/{bk_biz_id}/sessions/{session_code}

### 路径参数

| 参数名称         | 参数类型   | 必选 | 描述                           |
|--------------|--------|----|------------------------------|
| bk_biz_id    | int64  | 是  | 蓝鲸业务 ID       |
| session_code | string | 是  | 会话对外标识，由创建接口返回的 session_code |

### 输入参数

| 参数名称         | 参数类型   | 必选 | 描述     |
|--------------|--------|----|--------|
| session_name | string | 是  | 新的会话名称 |

### 调用示例

```json
{
  "session_name": "修改后的业务会话名称"
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述                 |
|---------|--------|--------------------|
| code    | int32  | 状态码                |
| message | string | 请求信息               |
| data    | null   | 更新操作无返回数据，固定为 null |

### 错误码说明

| code    | 描述                                               |
|---------|--------------------------------------------------|
| 2000001 | 请求参数错误，例如路径参数 `bk_biz_id` 为空、为 0 或负数，或会话名称为空 |
| 2000003 | `session_code` 对应会话不存在                           |
| 2000006 | 更新会话失败                                           |
| 2000012 | 用户无指定业务的「业务-智能体助手」Update 权限，或会话不属于当前用户/当前业务 |
