### 描述

- 该接口提供版本：v9.9.9.9+。
- 该接口所需权限：业务访问。
- 该接口功能描述：撤销当前用户在指定业务下对某一轮 Agent 对话的反馈。前端再点一次已选中的点赞 / 点踩按钮时调用。只能删除自己的、且属于当前业务的反馈。

### URL

DELETE /api/v1/agent/bizs/{bk_biz_id}/feedback/{run_id}

### 路径参数

| 参数名称      | 参数类型   | 必选 | 描述            |
|-----------|--------|----|---------------|
| bk_biz_id | int64  | 是  | 蓝鲸业务 ID       |
| run_id    | string | 是  | 本轮对话的 run ID |

### 查询参数

| 参数名称       | 参数类型   | 必选 | 描述                                         |
|------------|--------|----|--------------------------------------------|
| session_id | string | 是  | 所属会话 ID，必须是当前用户、当前业务下的会话，且与该条反馈的 `session_id` 一致 |

### 调用示例

```
DELETE /api/v1/agent/bizs/123/feedback/x9y8z7w6?session_id=s1
```

无请求体。

### 响应示例

```json
{
  "code": 0,
  "message": "ok",
  "data": null
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述                 |
|---------|--------|--------------------|
| code    | int32  | 状态码                |
| message | string | 请求信息               |
| data    | null   | 删除操作无返回数据，固定为 null |

### 错误码说明

| code    | 描述                                                      |
|---------|---------------------------------------------------------|
| 2000001 | 请求参数错误，例如路径参数 `bk_biz_id` 为空、为 0 或负数，或缺少 `session_id` |
| 2000003 | `session_id` 对应会话不存在，或 `run_id` 对应反馈不存在                  |
| 2000006 | 删除反馈失败                                                  |
| 2000012 | 用户无指定业务的「业务访问」权限，或会话 / 该反馈不属于当前用户 / 当前业务 / 该会话 |
