### 描述

- 该接口提供版本：v9.9.9+。
- 该接口所需权限：无。
- 该接口功能描述：取消正在进行的 AI Agent Run。当用户在等待回复时主动点击「停止」，客户端调用此接口终止服务端正在进行的 LLM 推理。

### URL

POST /api/v1/agent/cancel

### 输入参数

| 参数名称        | 参数类型   | 必选 | 描述                                          |
|-------------|--------|----|---------------------------------------------|
| sessionCode | string | 是  | 会话对外标识，由创建会话接口返回。服务端自动解析为内部 threadId 并注入 runId |

### 调用示例

```json
{
  "sessionCode": "e3f4a2b1c9d8e7f6a5b4c3d2-2026032009"
}
```

### 响应说明

| HTTP 状态码 | 描述                                     |
|----------|----------------------------------------|
| 200      | 取消成功，对应 Run 已被终止                       |
| 404      | 该 sessionCode 对应的会话无正在进行的 Run，无需取消     |
| 400      | 请求参数错误（sessionCode 缺失、为空或无效）           |


### 补充说明

- 即使客户端断开 `/agui` 的 SSE 连接，服务端也会在后台继续执行 LLM 调用。必须显式调用 `cancel` 接口或等待一次对话完全结束。
- Cancel 通过 `{appName, userID, threadId}` 三元组定位进行中的 Run，因此调用时的 `X-Bkapi-User-Name` 必须与发起 Run 时一致。
