### 描述

- 该接口提供版本：v1.9.2.2+。
- 该接口所需权限：服务-机房裁撤。
- 该接口功能描述：查询裁撤主机的裁撤截止时间列表，按截止时间去重、升序、去空后全量返回。

### URL

POST /api/v1/woa/dissolve/expect_abolish_time/list

### 输入参数

| 参数名称   | 参数类型   | 必选 | 描述       |
|--------|--------|----|----------|
| filter | object | 否  | 查询过滤条件，为空则不额外限制 |

#### filter

| 参数名称  | 参数类型        | 必选 | 描述                                                              |
|-------|-------------|----|-----------------------------------------------------------------|
| op    | enum string | 是  | 操作符（枚举值：and、or）。如果是and，则表示多个rule之间是且的关系；如果是or，则表示多个rule之间是或的关系。 |
| rules | array       | 是  | 过滤规则，最多设置5个rules。如果rules为空数组，op（操作符）将没有作用，代表查询全部数据。             |

#### rules[n]

| 参数名称  | 参数类型        | 必选 | 描述                                          |
|-------|-------------|----|---------------------------------------------|
| field | string      | 是  | 查询条件Field名称，具体可使用的用于查询的字段及其说明请看下面 - 查询参数介绍  |
| op    | enum string | 是  | 操作符（枚举值：eq、neq、gt、gte、lt、lte、in、nin、cs、cis） |
| value | 可变类型        | 是  | 查询条件Value值                                  |

#### 查询参数介绍：

| 参数名称                | 参数类型   | 描述                             |
|---------------------|--------|--------------------------------|
| project_id          | int    | 裁撤项目ID                         |
| bk_biz_id           | int64  | 业务ID                           |
| group_id            | int64  | 运维小组ID                         |
| region              | string | 地域ID                           |
| abolish_phase       | string | 裁撤阶段                           |
| expect_abolish_time | string | 裁撤截止时间，格式 yyyy-MM-dd           |

> 说明：接口内部恒定附加 `is_ignore=false` 与排除指定项目的过滤条件，与裁撤总览/明细查询口径一致。

### 调用示例

查询裁撤项目 ID 为 1、2 的全部裁撤截止时间。

```json
{
  "filter": {
    "op": "and",
    "rules": [
      {
        "field": "project_id",
        "op": "in",
        "value": [1, 2]
      }
    ]
  }
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "",
  "data": {
    "expect_abolish_times": ["2026-06-30", "2026-09-30", "2026-12-31"]
  }
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述   |
|---------|--------|------|
| code    | int32  | 状态码  |
| message | string | 请求信息 |
| data    | object | 响应数据 |

#### data

| 参数名称                 | 参数类型         | 描述                        |
|----------------------|--------------|---------------------------|
| expect_abolish_times | string array | 去重升序的裁撤截止时间列表，格式 yyyy-MM-dd |
