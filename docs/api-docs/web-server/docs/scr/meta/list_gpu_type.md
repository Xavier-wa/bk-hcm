### 描述

- 该接口提供版本：v9.9.9.9+。
- 该接口所需权限：无。
- 该接口功能描述：查询当前可筛选的 GPU 卡类型枚举。仅包含同步且可用机型上的真实卡型号；不含空串、「无」、手动创建机型以及已下线机型。

### URL

GET /api/v1/woa/meta/gpu_type/list

### 输入参数

无

### 响应示例

```json
{
  "code": 0,
  "message": "",
  "data": {
    "details": [
      "NVIDIA A100",
      "NVIDIA H20",
      "V100"
    ]
  }
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述   |
|---------|--------|------|
| code    | int    | 状态码  |
| message | string | 请求信息 |
| data    | object | 响应数据 |

#### data

| 参数名称    | 参数类型         | 描述        |
|---------|--------------|-----------|
| details | string array | GPU 卡类型列表 |
