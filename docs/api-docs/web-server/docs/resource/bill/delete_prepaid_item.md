
### 描述

- 该接口提供版本：v1.9.2.16。
- 该接口所需权限：预付费账单删除（二级账号实例级）。
- 该接口功能描述：批量删除预付费账单主单及其派生调账，仅未定账且关联调账非推送中的订单月可删；任一主单已定账或任一关联调账处于推送中时整批拒绝、零变更。无匹配记录或无授权实例时返回 `deleted_count=0`。
### URL

DELETE /api/v1/account/bills/prepaid_items/batch

### 输入参数

| 参数名称                  | 参数类型 | 必选 | 描述                                      |
|-----------------------|------|----|-----------------------------------------|
| order_year            | int  | 是  | 订单年份                  |
| order_month           | int  | 是  | 订单月份，取值 1-12                            |
| main_account_cloud_ids | string array | 否  | 二级账号的云上账号 ID 列表 |

### 调用示例

```json
{
  "order_year": 2026,
  "order_month": 7,
  "main_account_cloud_ids": ["123456789012", "210987654321"]
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "",
  "data": {
    "deleted_count": 2
  }
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述   |
|---------|--------|------|
| code    | int    | 状态码  |
| message | string | 请求信息 |
| data    | object | 响应数据 |

#### data

| 参数名称          | 参数类型 | 描述                                      |
|---------------|------|-----------------------------------------|
| deleted_count | int  | 实际删除的预付费主单条数，无匹配记录或无授权实例时为 0 |
