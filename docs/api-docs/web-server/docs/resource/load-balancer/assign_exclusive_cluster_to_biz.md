### 描述

- 该接口提供版本：v9.9.9.9+。
- 该接口所需权限：负载均衡操作。
- 该接口功能描述：分配负载均衡独占集群到业务下。

### URL

POST /api/v1/cloud/load_balancers/exclusive_clusters/assign/bizs

### 输入参数

| 参数名称        | 参数类型         | 必选 | 描述                                          |
|-------------|--------------|----|---------------------------------------------|
| cluster_ids | string array | 是  | 独占集群的本地ID列表，取自集群列表接口返回的 `id`，最多100个         |
| bk_biz_id   | int64        | 是  | 业务的ID，必须大于0                                 |

说明：

- 目标业务必须在集群所属账号的可用业务范围内，否则拒绝。
- 已分配给**其它**业务的集群不可再分配，列表中存在此类集群时整批拒绝，返回 `InvalidParameter`；已分配给目标业务本身的集群视为幂等，随批次一起返回成功。
- 不支持解绑（`bk_biz_id` 改回 -1）或重新分配（已分配给其它业务的集群改分配给新业务）。
- 分配操作会记录审计。

### 调用示例

```json
{
  "cluster_ids": [
    "00000001",
    "00000002"
  ],
  "bk_biz_id": 3
}
```

### 响应示例

```json
{
  "code": 0,
  "message": "ok"
}
```

### 响应参数说明

| 参数名称    | 参数类型   | 描述   |
|---------|--------|------|
| code    | int32  | 状态码  |
| message | string | 请求信息 |
